# Mother Templates — AI-Courses 核心母版库

更新时间：2026-09-01
状态：INTERNAL R&D ASSET

本目录存放 AI-Courses 的稳定课程母版。

> **少数稳定母版 × 主题/内容/规则/挑战组合 = 大量不同课次与学生作品。**

这些母版不是给学生直接复制的“万能 Prompt”，而是课程研发、教师培训、故障恢复和展示标准的内部底座。

## 母版资产要求

每个正式母版最终应包含：

- DISPLAY-SAFE BASE；
- FALLBACK；
- Prompt / Task Skeleton；
- Theme Options；
- Feature / Rule Options；
- Wow Options；
- Recovery；
- Challenge；
- Teacher Demo；
- Showcase Standard；
- Known Failures。

## 渠道保护

完整母版、失败库、稳定 Prompt 组合和恢复策略属于课程方内部研发资产。

代理商/教师正式交付只获得其被授权课程、课次和版本所需的执行材料，不默认获得完整母版库、跨课程 Prompt 库、失败统计和下一版本研发计划。

详见 `docs/CHANNEL_MOAT_STRATEGY.md` 与 `docs/MOTHER_TEMPLATE_PRODUCTIZATION_SPEC_V0.1.md`。
