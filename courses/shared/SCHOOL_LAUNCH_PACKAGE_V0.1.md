## 2. 教师开课 Gate

教师至少完成：

1. 自己亲手做过当前母版 BASE；
2. 自己实际试玩并做过一次自然语言修改；
3. 自己触发过一次普通故障并会让AI修复；
4. 会使用 FALLBACK；
5. 会使用统一 Recovery；
6. 知道 BASE DEADLINE；
7. 能判断学生是否同时承担了过多复杂修改；
8. 知道快学生进入哪个 Challenge；
9. 知道本课最后5–10分钟必须停止什么；
10. 认知型课知道如何在3–5分钟内结束原则讲解并让学生进入真实作品动作。

正式教师认证框架见：
`TEACHER_TRAINING_AND_CERTIFICATION_V0.1.md`

## 3. 课程开课 Gate

某节课进入正式学校前，至少满足：

### DISPLAY
- 保底作品第一眼达到展示线；
- 低能力学生不需要做明显低配版；
- 有二维码/链接展示路径；
- 认知型课有可见 Before/After，而不是只有“学会了一个道理”。

### TIME
- 小学 BASE 目标 25–30分钟左右；
- 初中 BASE 目标 30–35分钟左右；
- **至少有一位授课教师按正式脚本完整走过本课，并记录真实 BASE 时间；**
- 内部走课不能只看 AI生成时间，必须包含试玩、修复和再验证；
- 延长课时不是完成 BASE 的必要条件。

### COMPLEXITY

标准 BASE 原则上：

> **1个主要复杂修改 + 1个低风险可见增强。**

如果一课要求基础学生同时完成多个高风险逻辑：
- 必须有实测证据；或
- 使用预验证规则组合；或
- 降级到 Guided/Challenge。

### TEACHER LOAD
- 常见问题有统一恢复；
- 多人掉队时有全班兜底；
- 不依赖教师逐台写代码；
- 内部走课中不得出现“只有技术强教师才能救”的系统性问题。

### OWNERSHIP
- 学生至少有真实主题/内容/规则/功能选择；
- 不能只是复制同一个成品。

### LEARNING
至少经历：
> 生成/使用 → 实际试玩 → 判断 → 修改 → 再验证

认知型课还应体现：
> AI/用户/来源给出外部信息 → 学生判断 → 产品发生可见改变

## 5. 首次进学校时的版本定位

首批学校不需要假装“最终成熟版”。

建议内部标记：
> **School Launch V0.8 / Early Delivery**

对外可使用正式课程名称，不需要向家长暴露内部研发版本编号。

课程方明确：
- 教学目标稳定；
- 已使用的核心母版有证据；
- 展示级 BASE 已产品化；
- 课堂细节会基于真实数据继续优化。

---

## 6. 第一批学校优先观察什么

不要重新证明“学生喜欢不喜欢 AI”这种宽泛问题。

重点观察：

1. 展示级完成率；
2. FALLBACK使用率；
3. 老师逐个救援负担；
4. BASE真实完成时间；
5. 同时承担>1复杂修改的学生比例；
6. 最常见学生表达困难；
7. 哪些 Challenge 形成强创意；
8. 哪些作品最打动学校/家长；
9. 哪些课最容易成为“一键生成”；
10. 哪些认知动作没有真正发生；
11. 哪些认知课的 Before/After 不明显；
12. 多个班重复出现的问题。

## 7. 对代理商的交付包

代理商/教师拿到：

- 当前授权课表；
- 逐课教师脚本；
- 课堂卡；
- 学生任务卡；
- 教师演示版；
- 当前 BASE/FALLBACK；
- Recovery；
- Challenge；
- 学校展示模板；
- 反馈表；
- 培训/认证。

课程方内部保留：

- 完整母版研发库；
- 未发布项目；
- 全量失败案例和迭代历史；
- 渠道策略；
- 下一版本计划。

---

## 8. 首次课堂结束后的 24 小时内

教师/代理商只需提交：

- 真实课堂迭代表；
- 2–5个代表作品链接/二维码或截图；
- 一个最好案例；
- 一个最差/最卡案例；
- 一条最需要课程方修正的问题。

课程方不要求教师写长篇复盘。

---

## 9. 课程方迭代节奏建议

首发阶段：
- 每3–5个班做一次小复盘；
- 多班重复问题立即修课程资产；
- 个别偏好暂不大改；
- 高质量新 Challenge 快速入库；
- 高风险功能及时降级/移出 BASE；
- 如果某一 BASE Complexity 经常需要第二轮复杂修复，优先拆成 Guided/Challenge。

积累多校、多教师后，再做版本冻结。

---

## 10. 一句话首发标准

> **课程不需要在实验室里证明到完美才进学校；但一旦进学校，就必须保证成果、时间、复杂度、教师负担和展示都已经被产品化到可交付水平。**
