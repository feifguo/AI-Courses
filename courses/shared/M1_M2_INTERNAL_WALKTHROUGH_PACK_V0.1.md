# M1 / M2 内部走课包 V0.1

更新时间：2026-09-01
状态：READY FOR INTERNAL WALKTHROUGH
适用：小学高年级 / 初中基于 M1、M2 的已完成教案

## 1. 目的

M1 游戏、M2 学习平台已经真实账号 Known-Good。

本文件把它们从“研发母版”进一步转成老师内部走课时直接可用的展示资产：

- 教师3分钟演示；
- 学生简版任务卡；
- BASE完成线；
- FALLBACK判断；
- Challenge入口；
- 学校/家长展示样例。

原则：

> **老师看到的是完整方法，学生看到的是极简任务。**

不要把研发文档全文投给学生。

---

# 2. M1 游戏母版 — 教师演示版

## 2.1 演示时长

2–3分钟。

## 2.2 教师只展示四件事

1. 打开一个稳定主题游戏；
2. 玩一次基础规则；
3. 触发一个明显规则/反馈；
4. 展示二维码扫码试玩。

不要：
- 展示代码；
- 解释文件结构；
- 演示十个高级功能；
- 用过强教师样例把学生吓住。

## 2.3 推荐教师演示作品

### 太空记忆挑战

BASE：
- 12张卡 / 6对；
- 配对；
- 计分；
- 通关；
- 太空主题。

规则：
- 60秒倒计时。

低风险可见增强：
- 最后10秒变红；
- 通关火箭升空。

演示重点：

> “同一个基础游戏，只要学生换主题、改规则、改反馈，就会快速变成自己的版本。”

# 3. M1 学生屏幕任务卡

## 今天只做四件事

### ① 选一个你喜欢的主题

太空 / 恐龙 / 足球 / 海洋 / 赛车 / 昆虫 / 魔法 / 美食 / 自选。

### ② 先让它能玩

生成以后，自己完整玩一次。

### ③ 只加一条真正改变玩法的规则

例如：
- 倒计时；
- 连击；
- 错3次失败；
- 特殊奖励。

### ④ 给规则加一个看得见的效果

例如：
- 最后10秒变红；
- Combo动画；
- 徽章；
- 通关动画。

最后再完整玩一次。

> **AI说做好了不算，你自己玩通才算。**

---

# 4. M1 BASE 完成线

老师看到以下5项即可判定 BASE 成功：

- [ ] 能完整玩；
- [ ] 学生主题明显；
- [ ] 1条主要玩法规则工作；
- [ ] 1个可见反馈工作；
- [ ] 学生实际触发验证过。

此时即使突然下课，作品也已经可展示。

## M1 FALLBACK立即触发

出现任一：
- BASE Deadline仍没有稳定玩法；
- 新规则连续两次破坏基础游戏；
- 学生同时做2个以上复杂规则；
- 老师需要开始看代码。

统一说：

> “先回到最近能玩的版本，只留一条主要规则和一个可见效果。”

# 7. M2 学习平台 — 教师演示版

## 7.1 演示时长

3分钟左右。

## 7.2 教师只演示

1. 首页：主题、积分、进度；
2. 学习模式；
3. 闯关模式；
4. 故意答错一次，展示“先提示再给答案”；
5. 一个低风险奖励；
6. 二维码。

不要把教师演示做成有十几种学习算法的超级产品。

## 7.3 推荐教师演示作品

### 我的英语闯关基地

BASE：
- 4个主题；
- 学习；
- 10题闯关；
- 积分；
- 进度；
- 本地数据。

主要复杂规则：
- 第一次答错先提示，再给第二次机会。

可见增强：
- 完成主题出现徽章/动画。

演示重点：

> “AI不只能做游戏，学生可以真的设计一个帮助别人学习的软件。”

# 8. M2 学生屏幕任务卡

## 今天做一个真正的学习产品

### ① 选一个你喜欢/懂的主题

英语 / 成语 / 科学 / 地理 / 恐龙 / 昆虫 / 航天 / 足球 / 自选。

### ② 让它先能学习、能闯关

生成后真的学习几条、做几题。

### ③ 把一部分内容变成你的

改主题、改内容、加入自己知道的内容。

### ④ 只设计一条真正帮助学习的反馈规则

推荐：

> 第一次答错先给提示，让用户再试一次。

再加一个简单的可见奖励。

最后重新测试。

> **功能不是越多越好，真的帮助用户才重要。**

---

# 9. M2 BASE 完成线

老师检查：

- [ ] 首页有完整产品感；
- [ ] 至少一个主题完整可学；
- [ ] 闯关可完成；
- [ ] 积分/进度工作；
- [ ] 有学生自己的内容/主题；
- [ ] 1条主要学习反馈规则稳定；
- [ ] 1个低风险可见奖励；
- [ ] 学生实际故意答错并验证过。

## M2 FALLBACK立即触发

- 学习和答题内容不一致；
- 积分/进度损坏；
- 同时增加多个复杂学习规则；
- 为了高级奖励系统影响基础答题；
- 到 BASE Deadline核心流程仍不稳定。

统一说：

> “回最近稳定版，只留学习、闯关、积分/进度、一条聪明反馈和一个简单奖励。”
