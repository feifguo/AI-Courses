# 小学高年级 AI 创造课 — 16课时学期版 V0.3

更新时间：2026-09-01
状态：CURRENT SEMESTER STRUCTURE / INTERNAL AUDIT SYNCED / 部分母版待验证
年级：4–6年级
标准课时：40分钟
主平台：微信小程序教育平台

> V0.3 替代 V0.2 作为当前结构基线。重点：跨课去重、两课一个成果 Pair、展示里程碑、标准课时与 BASE Complexity Budget。

## 1. 产品承诺

一学期不是“学16次AI工具”，而是连续完成多种真正可玩的、可用的数字作品。

家长/学校持续看到：

> **每节都有变化，每两节有一个明显作品里程碑，每四节有一次新的能力/作品类型跃迁。**

学生持续经历：

> 想法 → AI第一版 → 试玩 → 找问题 → 修改 → 验证 → 同伴/用户反馈 → 再迭代。

---

## 2. 标准课时与复杂度硬约束

- 25–30分钟左右必须锁定 DISPLAY-SAFE BASE；
- 30–40分钟用于试玩、判断、修改、修复、收口；
- 40分钟以外才进入额外 Challenge / Open Creation；
- 弱学生有展示级 FALLBACK；
- 强学生完成 BASE 后立即继续，不等待全班。

内部走课审核新增：

> **标准 BASE 原则上只承担 1 个主要复杂修改 + 1 个低风险可见增强。**

AI生成省下来的时间优先留给试玩、修复、判断和自由创造，不继续往 BASE 堆第二、第三个复杂逻辑。

## 3. Showcase Pair 结构

### Pair 1 — L1/L2：我的第一款游戏

**L1 我做出了第一款游戏**  
M1 Known-Good。快速生成、主题个性化、第一次真实修改。

**L2 把游戏变得更好玩**  
审核后基础路径：**1条主要玩法规则 + 1个低风险可见反馈**。第二复杂规则进入 Guided / Challenge。

里程碑：
> **可扫码的个性化规则游戏。**

### Pair 2 — L3/L4：我的互动世界

**L3 互动冒险故事**  
依赖 M3：分支选择、多结局。

**L4 让世界活起来**  
依赖 M3：状态、任务、收藏、隐藏路线。

里程碑：
> **一个会因为选择而变化的互动世界。**

状态：等待 M3 最小实测。

### Pair 3 — L5/L6：我的兴趣博物馆

**L5 我的兴趣博物馆**  
依赖 M4：展区、展品、收藏、视觉结构。

**L6 把博物馆变成知识闯关**  
正式默认直接升级 L5：馆内挑战、探索进度、Boss题、成就。

里程碑：
> **能逛、能学、能玩的数字博物馆。**

状态：等待 M4。现有 M2 独立知识闯关只保留 Backup，不作为默认正式路径。

### Pair 4 — L7/L8：我做了一个真正学习 App

**L7 我做了一个学习 App**  
M2 Known-Good：多主题、学习、闯关、积分、进度。

**L8 让学习 App 真的会教人**  
审核后 BASE：**1条真正帮助学习的聪明反馈规则 + 1个低风险可见奖励**。推荐“第一次答错先提示、再给第二次机会”；超级模式、复杂连胜等进入 Challenge。

里程碑：
> **像真正产品一样工作的个性化学习平台。**

### Pair 5 — L9/L10：我解决一个校园小问题

**L9 校园工具第一版**  
依赖 M5：校园/学习/记录工具。

**L10 让它像真正产品**  
依赖 M5：多页面、状态、本地记录、进度、反馈。

里程碑：
> **看起来很复杂、实际上技术门槛很低的真实小工具。**

状态：等待 M5。

### Pair 6 — L11/L12：别人会用，而且它值得相信

**L11 别人真的会用吗**  
真人同伴试玩、反馈取舍、再迭代。

**L12 AI也会说错**  
审核后 BASE：核查**2条关键事实**，至少处理1个错误/不严谨/来源问题，并在产品中加入明显“已核查/来源/纠错”可视模块。第3条和多来源比较进入 Challenge。

里程碑：
> **经过用户和事实双重检查、并能看见 Before/After 的成熟产品。**

### Pair 7 — L13/L14：这是我的最终产品

**L13 最终产品 V1**  
当前支持 M1/M2；M3–M5 通过后扩完整菜单。必须当堂出现 V1，不写整节策划。

**L14 把 V1 做成我自己的 V2**  
V2 最终要明显属于学生自己，但**这些是累计状态，不代表 L14 当堂新造多个复杂功能**。本节仍遵守 1 个主要复杂升级的预算。

里程碑：
> **明显属于学生自己的 Final V2。**

### Pair 8 — L15/L16：发布与嘉年华

**L15 产品测试与发布**  
停止无止境加功能，做 Release QA、锁稳定版、二维码、截图。

**L16 AI Creator 嘉年华**  
作品墙、扫码试玩、30秒介绍、学校/家长展示。

最终里程碑：
> **全员可展示的 AI Creator 作品展。**

## 4. 学期能力跃迁

### Phase 1 — 我能做出来（L1–L4）
重点：选择、表达一个小修改、试玩、规则和分支。

### Phase 2 — 我能做真正产品（L5–L10）
重点：信息结构、学习逻辑、产品用途、状态与记录。

### Phase 3 — 我会判断和验证（L11–L12）
重点：用户反馈、事实核查、AI不等于权威；认知动作必须留下可见产品变化。

### Phase 4 — 这是我的产品（L13–L16）
重点：原创选择、取舍、QA、发布、表达。

## 8. 课程淘汰线

- BASE经常接近40分钟才完成；
- BASE基础路径同时承担多个未稳定复杂修改；
- 两节课表面产品高度重复却没有明显能力跃迁；
- 保底版本明显像“差生版”；
- 教师必须逐个技术救援；
- Challenge变成基础完成条件；
- 认知/伦理课连续10分钟没有学生操作真实作品；
- 认知/伦理课没有肉眼可见 Before/After；
- 家长/学校无法10秒理解本节成果。
