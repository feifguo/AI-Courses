# 小学高年级 L13 — 我的最终产品 V1 V0.1

更新时间：2026-09-01
状态：CONDITIONAL READY / 当前正式支持 M1、M2；完整菜单待 M3–M5
年级：4–6年级
标准课时：40分钟
主机制：范围控制 / 稳定母版上的原创 V1
平台：微信小程序教育平台

## 1. 本节课对外成果

每名学生必须在本节课结束前拥有：

> **一个已经可以打开、试玩、展示的最终项目 V1。**

禁止整节课只写“项目策划书”。

当前已验证可选产品：
- M1 游戏；
- M2 学习/知识产品。

M3互动故事、M4兴趣馆、M5校园工具只有在对应母版通过后才进入正式菜单。

## 2. 本节四个决定

每名学生只需先决定：
1. **给谁用/玩？**
2. **主题是什么？**
3. **最重要的3个功能/规则是什么？**
4. **第一眼 Wow 是什么？**

低能力学生从菜单选；强学生可自定义。

## 3. 40分钟时间盒

### 0–5分钟 — 看最终作品上限
教师展示一款完整 M1、一款完整 M2，不讲技术。

### 5–9分钟 — 选母版与主题
学生必须快速选定，避免长时间空想。

### 9–13分钟 — 四个决定
填写简单项目卡。

### 13–20分钟 — 生成/建立 V1
基础学生从稳定 BASE 起点开始；强学生可减少模板。

### 20–28分钟 — BASE DEADLINE：完成个人化
至少完成：
- 主题/视觉；
- 一个自己的规则/学习逻辑；
- 一个个人内容模块；
- 一个 Wow 效果。

到28分钟必须已有 DISPLAY-SAFE V1。

### 28–34分钟 — 完整试玩
学生自己走核心流程，发现一个问题就修一个。

### 34–37分钟 — Challenge / 收口
快学生可增加一个功能；慢学生停止新增、保存稳定版。

### 37–40分钟 — V1锁定
保存：
- 产品名；
- 二维码/体验入口；
- 最佳截图；
- 项目卡。

## 4. DISPLAY-SAFE BASE
- 产品可完整运行；
- 至少3处明显学生选择；
- 一个核心功能/规则属于学生决定；
- 有展示 Wow；
- 可扫码；
- 不依赖最后两节才能“第一次做出来”。

## 5. FALLBACK
若学生范围过大：
> 只保留1个核心目标和3个以内核心功能，先用课程方稳定母版做出完整V1。把其他想法放进“以后可以加”。

若28分钟仍不稳定：直接切回 M1/M2 稳定母版，并保留学生主题、内容、一个规则和一个 Wow。

## 6. Challenge
- 游戏：多关卡/特殊机制；
- 学习产品：新题型/自定义内容/奖励机制；
- Open Creator：自己定义一个新功能，但一次只做一个。

## 7. 教师追问
“我想做十个功能” → “如果家长只能体验30秒，哪三个最重要？”

“我想完全从空白做” → “你先拿到一个稳定 V1，再决定哪些地方要摆脱母版。”

## 8. 课后教师最小记录
- V1按时完成率；
- M1/M2选择比例；
- FALLBACK人数；
- 最常见范围过大问题；
- 最强学生脱离模板的方式；
- 哪些新项目需求最值得未来做成母版。
