# 小学高年级 L14 — 把 V1 做成“我自己的” V0.1

更新时间：2026-09-01
状态：CONDITIONAL READY / 通用迭代机制可走课
年级：4–6年级
标准课时：40分钟
主机制：个性化 / 原创功能 / 稳定 V2
适用：当前 M1/M2；未来扩展 M3–M5

## 1. 本节课对外成果

每名学生把最终项目 V1 升级成：

> **明显和课程母版、同学作品不一样的 V2。**

最低必须出现四类差异中的三类：
- 视觉/主题；
- 内容；
- 规则/功能；
- Wow效果。

## 2. 核心观念

教师开场展示三个同母版、但成品明显不同的作品。

只问：
> “底层一样，为什么看起来像三个人的产品？”

结论：
> **用模板不是问题，最后有没有做自己的决定才是问题。**

## 3. 40分钟时间盒

### 0–5分钟 — 找到 V1 最像模板的地方
学生在作品上指出：
- 哪一处最像默认模板；
- 哪一处最不符合自己想法。

### 5–9分钟 — 选三类差异
从：视觉 / 内容 / 规则 / Wow 中至少选三类。

### 9–16分钟 — 第一轮：内容或视觉
让作品第一眼更属于自己。

### 16–23分钟 — 第二轮：真实规则/功能
不能只换颜色。

模板：
> 我希望这个产品在【情况】时新增/改变【功能】，因为我想让用户【体验/目标】。请实现并保留已有稳定功能。

### 23–29分钟 — BASE DEADLINE：增加 Wow
基础学生从 Wow 菜单选：
- 完成动画；
- 解锁；
- 成就；
- 特殊反馈；
- 主题动态效果。

到29分钟必须有明显差异化 V2。

### 29–34分钟 — 同伴“找模板”测试
同学回答：
> “我一眼能看出哪三处是你自己设计的吗？”

若看不出，学生再改一处。

### 34–37分钟 — Challenge / 收口
强学生开放增加一个原创功能；普通学生验证稳定性。

### 37–40分钟 — V2锁定
保存截图、二维码、写一句：
> “这个作品最属于我的地方是……”

## 4. DISPLAY-SAFE BASE
- V1核心流程稳定；
- 至少三类明显差异；
- 至少一个真实规则/功能差异；
- 一个 Wow；
- 可试玩、可展示。

## 5. FALLBACK
如果个性化导致产品失效：
> 回到 V1 稳定版，只重新做视觉/内容 + 一条已验证规则 + 一个低风险 Wow。保留学生主题，停止高风险重构。

## 6. Challenge
- 新模式；
- 新页面；
- 完全自定义规则；
- 用户自定义内容；
- 让同学提出一个创意再由作者决定是否采用。

## 7. 教师追问
“我换了颜色就行吗？” → “玩法/功能哪里体现你自己的决定？”

“我想完全重做” → “先保住稳定版，再改最值得变的地方。”

## 8. 课后教师最小记录
- V2差异化完成率；
- 只做换皮的学生比例；
- FALLBACK人数；
- 最受欢迎原创功能；
- 最容易把稳定作品改坏的拓展；
- 2个“同母版但差异巨大”的展示案例。
