# 小学高年级 L6 — 把知识变成闯关 V0.1

更新时间：2026-09-01
状态：CONDITIONAL READY / 当前用 M2 闯关机制；完整 M4 兴趣馆组合待验证
年级：4–6年级
标准课时：40分钟
主母版：M2 Quiz Engine

## 1. 本节课对外成果

每名学生完成：

> **一个围绕自己兴趣/知识主题的可玩闯关系统：10题、即时反馈、积分、通关奖励，并至少加入一条自己的规则。**

若 M4 尚未通过，本课可以独立用 M2 完成，不等待兴趣馆。

## 2. 能力暗线
- 把知识内容变成可玩的交互；
- 判断题目是否适合目标用户；
- 设计反馈而不是只判对错；
- 实际试玩；
- 发现题目/答案问题并修正。

## 3. 40分钟时间盒

### 0–4分钟 — 玩一轮示例
教师演示10题闯关+通关奖励。

### 4–8分钟 — 选主题与用户
学生从兴趣/学科主题中选一个，并确定给谁玩。

### 8–15分钟 — 第一版闯关
任务骨架：
> 给我的【主题】做一个10题四选一闯关。每题答完立即反馈，答对加10分，答错告诉我哪里错；最后显示总分和通关评价。界面有游戏感，保留我的主题风格。不要让我写代码。

### 15–21分钟 — 试玩5题并改内容
至少检查：
- 题目看得懂吗；
- 答案对吗；
- 难度合适吗。

### 21–29分钟 — BASE DEADLINE：加一条规则
基础菜单：
- 连胜；
- Boss题；
- 错题再挑战；
- 60秒挑战；
- 通关徽章；
- 分难度。

到29分钟必须有完整、可玩的 DISPLAY-SAFE BASE。

### 29–34分钟 — 同伴试玩
交换做5题，反馈：太难/太简单/最有意思的一题。

### 34–37分钟 — Challenge / 修正
快学生增加第二规则；慢学生修题、锁稳定版。

### 37–40分钟 — 展示
学生说：
> “我做的是【主题】挑战，我自己设计的一条规则是【规则】。”

## 4. DISPLAY-SAFE BASE
- 10题；
- 正确反馈；
- 积分；
- 通关；
- 一个学生主题；
- 一条学生规则；
- 可完整试玩。

## 5. FALLBACK
若题库/规则冲突：
> 只保留10题四选一、基础积分和一个通关奖励，暂时移除复杂规则；先保证每道题都能正常作答和反馈。

## 6. Challenge
- 多难度；
- Boss；
- 错题复习；
- 用户自己出题；
- 隐藏奖励。

## 7. 课后教师最小记录
- 10题稳定完成率；
- 错误题目比例；
- 最受欢迎规则；
- 学生是否会根据同伴反馈调整难度；
- M4通过后哪些内容最适合并入兴趣馆。
