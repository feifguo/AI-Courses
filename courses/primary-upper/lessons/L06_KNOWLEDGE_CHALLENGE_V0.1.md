# 小学高年级 L6 — 把知识变成闯关 V0.1

更新时间：2026-09-01
状态：BACKUP / CONDITIONAL PATH — 正式默认等待 M4
年级：4–6年级
标准课时：40分钟
主机制：M2 Quiz Engine 可独立成立；正式学期优先作为 M4 兴趣馆的第二课

## 1. 当前定位

本课的“知识闯关”机制已经可以用已验证 M2 独立完成，但**不建议在正式16课时默认采用“M2独立闯关 → 下一课又做M2学习App”**。

原因：连续两课表面产品过于相似，学生和家长可能感受到：

> “又是知识/答题产品。”

因此正式理想路径是：

- L5：M4 兴趣博物馆；
- L6：在同一个博物馆里加入知识闯关、探索进度、Boss题和奖励；
- L7：切换到明显不同的完整学习 App。

只有以下情况使用本文件的 M2 独立路径：

- M4 尚未通过但临时需要替代课；
- 短期工作坊；
- 单独知识闯关活动；
- 某校不采用兴趣馆单元。

## 2. 对外成果

> **一个围绕自己兴趣/知识主题的可玩闯关系统：10题、即时反馈、积分、通关奖励，并至少加入一条自己的规则。**

如果与 M4 组合，则成果应呈现为：

> **“我的数字博物馆现在真的可以探索、答题和通关。”**

而不是另起一个相似学习产品。

## 3. 能力暗线

- 把知识内容变成可玩的交互；
- 判断题目是否适合目标用户；
- 设计反馈而不是只判对错；
- 实际试玩；
- 发现题目/答案问题并修正。

## 4. 40分钟 Backup 时间盒

### 0–4分钟 — 玩一轮示例
教师演示10题闯关+通关奖励。

### 4–8分钟 — 选主题与用户
学生从兴趣/学科主题中选一个，并确定给谁玩。

### 8–15分钟 — 第一版闯关

> 给我的【主题】做一个10题四选一闯关。每题答完立即反馈，答对加10分，答错告诉我哪里错；最后显示总分和通关评价。界面有游戏感，保留我的主题风格。不要让我写代码。

### 15–21分钟 — 试玩5题并改内容
检查题目可读性、答案和难度。

### 21–29分钟 — BASE DEADLINE：加一条规则
- 连胜；
- Boss题；
- 错题再挑战；
- 60秒挑战；
- 通关徽章；
- 分难度。

到29分钟必须有完整可玩的 DISPLAY-SAFE BASE。

### 29–34分钟 — 同伴试玩
反馈：太难/太简单/最有意思的一题。

### 34–37分钟 — Challenge / 修正
快学生增加第二规则；慢学生修题、锁稳定版。

### 37–40分钟 — 展示
> “我做的是【主题】挑战，我自己设计的一条规则是【规则】。”

## 5. DISPLAY-SAFE BASE

- 10题；
- 正确反馈；
- 积分；
- 通关；
- 一个学生主题；
- 一条学生规则；
- 可完整试玩。

## 6. FALLBACK

> 只保留10题四选一、基础积分和一个通关奖励，暂时移除复杂规则；先保证每道题都能正常作答和反馈。

## 7. Challenge

- 多难度；
- Boss；
- 错题复习；
- 用户自己出题；
- 隐藏奖励。

## 8. M4 通过后的正式升级

M4 Strong Pass 后，应重写本课主版本，使学生**直接在 L5 已做的兴趣馆里加**：

- 10题馆内挑战；
- 参观进度；
- 看过展品才能解锁的题；
- 收藏/探索成就；
- 最终 Boss 题。

届时本文件保留为 Backup，不作为主课版本。

## 9. 课后教师最小记录

- 10题稳定完成率；
- 错误题目比例；
- 最受欢迎规则；
- 是否与 L7 产生明显产品重复；
- M4通过后最值得迁入兴趣馆的玩法。
