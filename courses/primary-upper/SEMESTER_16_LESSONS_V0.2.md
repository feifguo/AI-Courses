# 小学高年级 AI 创造课 — 16课时学期版 V0.2

更新时间：2026-09-01
状态：STANDARD-PERIOD PRODUCT STRUCTURE / 待逐课母版与内部走课

建议年级：4–6 年级
标准单课时：40 分钟
主平台：微信小程序教育平台（当前 Known-Good）

> V0.2 替代 V0.1 作为当前课程结构基线。V0.1 保留历史参考，其“45–60分钟”默认时长已被本版修正。

## 1. 课程承诺

一学期结束，家长/学校看到的不是“孩子学了提示词”，而是一组真的可以打开、试玩、扫码体验的数字作品。

学生感受：

> **“原来我可以用 AI 把自己的想法做成真正能玩的、能用的软件。”**

学校/家长感受：

> **“这真的是小学四五六年级学生做的吗？”**

## 2. 标准课时硬约束

每节课必须同时满足：

1. **25–30 分钟左右锁定 DISPLAY-SAFE BASE；**
2. 30–40 分钟用于试玩、找问题、做一次修改、收口或展示；
3. 如果学生提前完成，不等待，立即进入 Challenge Pool / Open Creation；
4. 如果学校安排 50/60/90 分钟，额外时间只用于更深创作，不补主流程；
5. 最弱路径也达到展示级，不允许“差生版”明显廉价；
6. BASE DEADLINE 前仍未达展示线的学生立即启用 FALLBACK；
7. 老师可以必要时协助局部操作，但高频问题必须产品化成统一兜底；
8. AI 说“完成”不算完成，必须实际试玩/使用。

统一时间结构：

> **0–30 分钟：锁成果**  
> **30–40 分钟：把学习做实**  
> **40 分钟以后：把想象力放开**

详见：
- `../../docs/STANDARD_PERIOD_AND_EXTENSION_POLICY.md`
- `../../docs/CHALLENGE_POOL_SYSTEM_V1.md`
- `../../docs/OUTCOME_FIRST_AND_SCAFFOLDING_POLICY.md`

## 3. 一学期能力跃迁

### Unit 1 — 我能做出来（L1–L4）
从零到多个真正可玩的数字作品，先建立能力信念。

### Unit 2 — 我能让它更好玩、更好用（L5–L8）
从换主题进入规则、状态、反馈、产品结构。

### Unit 3 — 我能解决一个真实的小问题（L9–L12）
从“作品”进入“产品”，加入用户、内容、判断和验证。

### Unit 4 — 这是我的产品（L13–L16）
学生在稳定产品母版上做综合原创，并完成公开展示。

# Unit 1 — 我能做出来

## 第1课：我做出了第一款游戏

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
一个可扫码试玩、主题明显个性化的记忆翻牌小游戏。

### BASE
稳定翻牌骨架：
- 12张卡牌；
- 配对；
- 计分；
- 成功页；
- 动画；
- 二维码发布。

学生选择：
- 太空 / 恐龙 / 足球 / 海洋 / 魔法 / 自选；
- 卡牌内容；
- 背景风格；
- 通关特效。

### 标准课时深化
- 完整试玩一次；
- 找到一个不满意处；
- 做一次具体修改；
- 最后版本确认。

### CHALLENGE / 延长课时
- 倒计时；
- 连击；
- 特殊卡；
- 隐藏奖励；
- 完全自定义“我还想让它……”。

### 能力暗线
- AI 可以做第一版；
- 第一版必须试玩；
- 学会说一个清楚的小修改。

### 展示点
全班二维码游戏墙。

## 第2课：把游戏变得“更上头”

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
第一课小游戏升级成更完整的游戏版本。

### BASE
规则菜单任选两项：
- 60秒倒计时；
- 连续成功加分；
- 三次错误失败；
- 关卡升级；
- 通关动画；
- 成就徽章。

### 标准课时深化
- 试玩触发条件；
- 找一个规则没有按预期工作的地方；
- 用自然语言修正。

### CHALLENGE / 延长课时
学生自行设计新规则，并要求 AI 实现；可进入 Builder Challenge。

### 能力暗线
- 把“更好玩”说成具体规则；
- 判断规则有没有真的工作。

### 教师兜底
学生说不清时，直接从规则卡选择，不允许一直卡在“我不知道”。

## 第3课：我的互动冒险故事

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
一个可以点击选择、走向不同结局的互动故事小程序。

### BASE
稳定故事骨架：
- 开场页；
- 角色；
- 3次选择；
- 至少2种结局；
- 动画/视觉反馈。

主题菜单：
- 太空救援；
- 恐龙岛；
- 神秘古城；
- 海底世界；
- 魔法学院；
- 自选。

### 标准课时深化
- 自己试玩两条路线；
- 找一处选择/结局不合理处；
- 修改一次。

### CHALLENGE / 延长课时
- 隐藏结局；
- 道具系统；
- 分数/生命值；
- 多角色路线。

### 能力暗线
- 结果取决于规则与条件；
- 一个大故事需要拆成多个小选择。

## 第4课：让互动世界“活起来”

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
互动故事升级为带任务、状态或收藏机制的数字世界。

### BASE
从功能菜单增加1–2项：
- 收集物；
- 任务进度；
- 生命/能量；
- 奖励页；
- 地图页。

### 标准课时深化
- 检查新机制是否真的影响玩法；
- 修正一个状态或反馈问题。

### CHALLENGE / 延长课时
学生自己设计一个新机制；强学生可加入多条件或隐藏任务。

### 能力暗线
- 学会在现有作品上继续开发；
- 不要每次从头生成。

# Unit 2 — 我能让它更好玩、更好用

## 第5课：我的兴趣博物馆

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
一个像真正小应用的兴趣主题馆。

主题：恐龙、昆虫、汽车、足球、航天、海洋、动漫创作、音乐等。

### BASE
稳定产品骨架：
- 首页；
- 3–5个展区；
- 内容卡片；
- 图片；
- 收藏/喜欢；
- 小测验入口。

### 标准课时深化
- 检查信息是否一眼看懂；
- 改一个展区名称/内容组织/视觉层级。

### CHALLENGE / 延长课时
- 搜索；
- 收藏榜；
- 隐藏展品；
- 成就系统；
- 自定义新展区。

### 能力暗线
- 从“做页面”进入“设计信息结构”。

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果

## 第7课：我做了一个学习 App

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
一个完整的学习/兴趣学习平台。

可选：

### 标准课时深化

### CHALLENGE / 延长课时

### 能力暗线

## 第8课：让学习 App 真的“会教人”

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
学习 App 加入更聪明的反馈和游戏化。

### BASE
从已验证功能中选择：
- 第一次答错先给提示；
- 第二次再错才给答案；
- 不同情况不同得分；
- 连续答对进入超级模式；
- 最高连胜；
- 自定义主题。

### 标准课时深化
- 试玩不同答题情况；
- 检查提示/得分是否符合设计；
- 修正一处。

### CHALLENGE / 延长课时
自己设计一套奖励/学习逻辑；可加入个人学习主题。

### 能力暗线
- 不只是要求 AI “做功能”，而是设计别人怎么学。

# Unit 3 — 我能解决一个真实的小问题

## 第9课：校园里有什么值得我做一个小程序？

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
当天就做出一个“校园工具”第一版，而不是只讨论问题。

### BASE 产品菜单
- 校园导览；
- 社团活动中心；
- 图书推荐；
- 班级活动助手；
- 失物招领演示版；
- 环保挑战；
- 运动打卡；
- 课间小游戏中心。

每个选项都有稳定母版。

### 标准课时深化
- 说清“谁会用”；
- 试玩最核心流程；
- 修改一个让用户更容易使用的地方。

### CHALLENGE / 延长课时
自己提出校园问题并定义产品；强学生可自行决定功能结构。

### 能力暗线
- 谁会用？
- 他最需要什么？

## 第10课：让它看起来像“真的产品”

### 标准课时 BASE DEADLINE
约 25–30 分钟。

### 对外成果
校园产品从Demo升级为多页面、状态清楚的完整小应用。

### BASE
增加：
- 导航；
- 首页状态；
- 记录/收藏；
- 进度；
- 成就/反馈；
- 本地数据。

### 标准课时深化
- 检查主流程；
- 找一个冗余/不清楚的功能；
- 做一次删减或简化。

### CHALLENGE / 延长课时
自己决定哪些功能最重要，进一步增加/删除功能。

### 能力暗线
- 产品不是功能越多越好；
- 学会取舍。

---

## 第11课：别人真的会用我的产品吗？

### 标准课时 BASE DEADLINE
本课 BASE 是“获得反馈并完成一次可见修改”，目标约 30 分钟内完成。

### 对外成果
产品完成一次明显的“试玩前 vs 试玩后”升级。

### BASE
两两试玩，统一反馈卡：
- 我第一眼知道怎么用吗？
- 哪一步最方便？
- 哪一步最奇怪？
- 我最希望它再增加什么？

学生至少完成一次修改。

### 标准课时深化
学生说明：
- 我采纳了什么；或
- 我为什么不采纳。

### CHALLENGE / 延长课时
收集3名用户反馈并自己决定哪些不改；进行第二轮迭代。

### 能力暗线
- 用户反馈不是命令；
- 学会判断、选择、迭代。

---

## 第12课：AI也会说错——把作品做得更可信

### 标准课时 BASE DEADLINE
约 25–30 分钟完成3条事实核查和可信信息卡。

### 对外成果
给自己的知识型/校园型产品增加“可信信息卡/来源说明/纠错页”，同时完成一次视觉升级。

### BASE
选择作品中3条事实：
- 让 AI 给出；
- 再用教师提供的安全来源/搜索方式核查；
- 错的修改；
- 为产品增加“我核查过的信息”小卡片。

同时用文生图/素材功能优化一组视觉素材。

### 标准课时深化
- 检查一个表述是否容易误导；
- 用更清楚的方式重写。

### CHALLENGE / 延长课时
找到更多 AI 表述含糊或可能误导的地方；增加来源页或纠错记录。

### 能力暗线
- AI生成 ≠ 事实；
- 查证也是创造的一部分。

### 注意
不把本节做成伦理讲座，最终仍然有肉眼可见的产品升级。

# Unit 4 — 这是我的产品

## 第13课：我要做一个什么产品？

### 标准课时 BASE DEADLINE
约 25–30 分钟必须出现最终项目 V1。

### 对外成果
当堂出现最终项目 V1，不允许整节只写策划书。

### BASE 项目菜单
- 游戏；
- 互动故事/世界；
- 兴趣博物馆；
- 学习产品；
- 校园工具。

每类有 DISPLAY-SAFE 母版。

学生选择：
- 用户；
- 主题；
- 3个核心功能；
- 一个 Wow 效果。

### 标准课时深化
- 试玩 V1；
- 删除或修改一个过大的功能；
- 确认下节课最重要的升级。

### CHALLENGE / 延长课时
完全自定义项目；高能力学生可不使用完整母版。

### 能力暗线
- 目标与范围；
- 不要一口气做十个功能。

## 第14课：把 V1 做成“我自己的”

### 标准课时 BASE DEADLINE
约 25–30 分钟完成四类差异化中的至少三类。

### 对外成果
最终项目完成明显差异化。

### BASE
至少完成：
- 视觉/主题；
- 一个规则/功能修改；
- 一个个人内容模块；
- 一个 Wow 效果。

### 标准课时深化
- 试玩；
- 找一个“仍然很像模板”的地方；
- 再修改一次。

### CHALLENGE / 延长课时
新增页面、模式、复杂状态或自定义机制。

### 能力暗线
- 在稳定底座上形成所有权。

## 第15课：产品测试日

### 标准课时 BASE DEADLINE
约 30 分钟内必须形成可发布 Final Candidate。

### 对外成果
Final Candidate：完成用户测试后的正式展示候选版。

### BASE
- 同伴试玩；
- 找到一个问题；
- 修复；
- 检查所有按钮/流程；
- 发布二维码；
- 生成作品截图。

### 标准课时深化
- 做最终视觉收口；
- 准备一句作品介绍。

### CHALLENGE / 延长课时
让不同同学测试并比较反馈；继续做第二轮修订。

### 能力暗线
- AI说完成不算完成；
- 发布前要自己验收。

### FALLBACK
任何未达到展示线的作品，立即切换课程方母版并保留学生主题/内容，优先保证最终展示。

## 第16课：AI Creator 嘉年华

### 对外成果
学生作品展 + 二维码作品墙 + 学校宣传素材。

每名学生至少有：
- 一个可试玩最终作品；
- 一张作品卡；
- 二维码；
- 一张截图/海报；
- 30秒作品介绍。

学生只需回答：
1. 我做了什么；
2. 哪个地方是我自己决定的；
3. AI第一版哪里没做好；
4. 我后来怎么改。

### 标准40分钟版
采用轮转式展示，不要求每名学生全班口头演示：
- 0–8分钟：布置/确认二维码与作品卡；
- 8–28分钟：小组轮转试玩/参观；
- 28–36分钟：2–4个代表作品短展示；
- 36–40分钟：集体收口/合影/成果记录。

### 延长版
60–90分钟可增加：
- 更多学生发布；
- 家长/教师试玩；
- 最佳创意/最佳体验等非排名式标签；
- 30秒短视频录制；
- 更完整作品展。

### 对学校产出
- 优秀作品集；
- 作品二维码墙；
- 课堂/展示照片；
- 30秒学生短视频素材；
- 学期成果统计。

## 5. 当前未进入必修主线的内容

### 运行时大模型/AI智能体

目前不作为 DISPLAY-SAFE BASELINE。

原因：将实时大模型真正接入学生发布的小程序仍可能涉及 API、云开发、权限、审核或新能力内测。

当前课程的“AI原生”核心已经成立：

> **AI 是学生创作、修改、评审和修复产品的伙伴。**

未来平台提供稳定、学校友好的运行时 AI 后，可把 AI馆长/AI角色/AI助手加入高阶模块。
