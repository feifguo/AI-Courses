# 小学低年级 AI 创造方向（候选）

状态：**暂缓完整学期课研发，保留体验工作坊方向。**

## 1. 为什么不是当前第一优先

低年级并不是不适合 AI 创造，相反，“AI 魔法感”可能更强。但当前阶段直接研发完整一学期课程有几个明显风险：

- 阅读能力和键盘输入速度差异大；
- 抽象描述能力仍在发展；
- 学生容易把 AI 当成“按一下就出结果”的魔法按钮；
- 教师介入比例可能很高；
- 开放式生成工具在小学阶段有更严格的使用和管理边界；
- 如果为了降低难度只做图片/视频一键生成，作品所有权和能力培养会变弱。

因此当前资源优先投入小学高年级和初中，更容易同时做到：

> 低技术门槛 + 学生自主创造 + 会工作的作品 + 学校可复制。

## 2. 低年级未来更适合的交互方式

若后续开发，应避免依赖大量文字 Prompt 和键盘输入，优先探索：

- 说话；
- 画画；
- 拖拽；
- 选择卡片；
- 拍照；
- 教师预设安全 AI 入口；
- AI 把儿童素材变成互动结果；
- 屏幕作品与纸张/手工结合。

## 3. 潜在课程形态

更建议先做 30–60 分钟或半天的：

> **AI 魔法创造工作坊 / AI 小小创造家体验课**

而不是先做完整 12–16 节课。

候选体验：

- 我画的小怪兽活起来；
- 我的玩具会说话；
- 全班一起造一个会回答问题的故事世界；
- 把手绘地图变成互动探险；
- 用自己的声音和画做一个互动绘本。

关键仍然不是“生成得漂亮”，而是让孩子自己的画、声音、选择和故事成为作品核心。

## 4. 安全与课堂组织原则

设计时默认：

- 不让低年级学生独自自由使用开放式生成式 AI；
- 由教师组织、控制入口和内容范围；
- 不输入学生真实个人隐私；
- 优先使用封闭任务、模板化流程和适龄内容；
- 需要明确的教师巡视和成果审核；
- AI 生成不替代学生自己的绘画、口述、选择和表达。

## 5. 什么时候值得升级为正式学期课

至少满足以下条件再立项：

1. 小学高年级课程已验证稳定工具链；
2. 低年级可以主要靠语音/视觉而不是键盘操作；
3. 普通教师可以低负担管理全班；
4. 学生作品仍具有明显个体差异；
5. 不是一键生成；
6. 学校和家长对低年级产品有真实采购需求；
7. 课堂安全、账号、隐私和内容管理方案清晰。

## 6. 当前结论

> **保留产品机会，但不与当前两条主线抢研发资源。**

优先把低年级视作未来的体验课/科技节/家庭开放日产品，用小规模试验回答“能不能既简单、又真正是孩子自己的创造”。
