# 初中 L10 — AI也会胡说：让产品更可信 V0.1

更新时间：2026-09-01
状态：CONDITIONAL READY / 当前可基于 M2；完整 M4 知识产品案例待验证
年级：7–9年级
标准课时：45分钟
主机制：事实核查 / 来源判断 / 产品纠错

## 1. 本节课对外成果

每名学生把知识/信息型产品完成一次可信度升级：

> **核查至少3条关键事实，修正错误/不严谨表述，并增加来源/可信说明。**

最终作品仍然要更完整、更好展示，不能变成单纯“查资料课”。

## 2. 核心观念

教师展示：
- 一段语气非常肯定但实际错误/过度简化的 AI 内容；
- 一个可信来源中的不同表述。

问：
> “AI写得像百科全书，就等于它是事实吗？”

结论：
> **生成内容要进入产品，关键事实就要承担验证责任。**

## 3. 45分钟时间盒

### 0–5分钟 — 看一个“很像真的”错误
不使用政治/争议性材料，选择科学、地理、语言等稳定事实。

### 5–9分钟 — 选3条产品关键事实
优先选影响题目、解释、推荐或用户判断的内容。

### 9–17分钟 — 独立核查
使用教师指定可靠来源或学校允许资源。

每条标记：
- 支持；
- 冲突；
- 信息不足；
- 需要改得更准确。

### 17–24分钟 — 处理一条最重要问题
如果错误：修正。
如果来源冲突：改成更谨慎表述。
如果无法确认：明确“暂不确定”，不强行下结论。

### 24–33分钟 — BASE DEADLINE：把可信机制放回产品
增加：
- 来源卡；
- “已核查内容”；
- 纠错页；
- 参考资料入口；
- 更新时间（适合会变化的信息）。

到33分钟产品必须重新完整可用。

### 33–39分钟 — 检查关联内容
若事实改变，检查：
- 题目；
- 答案；
- 推荐；
- 说明文字；
- 统计/分类。

### 39–42分钟 — Challenge
比较两个来源的冲突表述，并写一句自己的判断理由。

### 42–45分钟 — 可信说明
学生说：
> “我原来用了【AI内容】，后来通过【来源】发现【问题】，所以改成【新表述】。”

## 4. DISPLAY-SAFE BASE
- 核查3条关键事实；
- 至少处理1条错误/不严谨/来源说明；
- 产品增加可信机制；
- 关联内容一致；
- 产品仍稳定可展示。

## 5. FALLBACK
若核查范围过大：只查3条最关键内容。

若不同来源冲突、学生无法判断：
> 保留两种可靠说法并明确“不同来源表述不同”，不要让 AI 替学生强行选一个。

## 6. 教师追问
“AI给了网址，所以是真的？” → “你真正打开并看了吗？”

“两个来源不一样怎么办？” → “它们是不是说的同一件事、同一时间、同一口径？”

“我懒得查” → “这条事实会不会影响用户的判断？”

## 7. Challenge
- 比较多个来源；
- 判断来源权威性；
- 给变化型数据增加更新时间；
- 让 AI 先列验证计划，但由学生自己查。

## 8. 课后教师最小记录
- 实际发现错误/不严谨内容比例；
- 学生最容易误判的来源类型；
- 哪些核查任务超出课时；
- 哪些来源最适合预置；
- 2个高质量“AI错→学生纠正”的案例。
