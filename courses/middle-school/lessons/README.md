## F. 内部走课新增硬规则

来自 `../../../docs/INTERNAL_WALKTHROUGH_AUDIT_V0.1.md`：

> **BASE Complexity Budget = 1个主要复杂修改 + 1个低风险可见增强。**

例外只有像 Rule Lab 这种“规则联动本身就是唯一教学目标”的课，且必须使用课程方预设组合。

认知型课：
- 单次原则讲解尽量3–5分钟；
- 连续10分钟没有学生操作真实作品视为设计预警；
- AI评审/事实核查/AI反方/用户测试必须留下可见 Before/After。

## G. 初中难度原则

初中不通过增加代码量来变难。

主要增加：

- 用户定义；
- 产品要求；
- 规则关系；
- 版本意识；
- 用户测试；
- AI意见判断；
- 功能取舍；
- 发布责任。

> **30–35分钟左右锁定展示级 BASE；35–45分钟做判断、测试、迭代和收口；额外时间才进入更复杂产品挑战。**
