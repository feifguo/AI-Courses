## 任务目标

使用真实微信小程序教育平台账号，完成 M5 的最小产品验证。

本任务与 M3、M4 完全独立，可以并行执行。

## 必须读取

1. `docs/MOTHER_TEMPLATE_VALIDATION_PROTOCOL_V1.md`
2. `docs/MOTHER_TEMPLATE_M3_M4_M5_RUN_CARDS.md`
3. `docs/CONTROLLED_DIVERGENCE_POLICY_V0.1.md`（执行分支）

## 执行范围

严格只跑：

1. 首版：我的学习驾驶舱；
2. 修改1：学习能量 + 等级；
3. 修改2：我的目标；
4. Challenge：本周总结。

不要额外扩功能。

## 硬规则

- 不手写代码；
- 不人工 Debug；
- 出错先用自然语言要求 AI 自修；
- 首版必须明显像现代工具，不是普通表单；
- 待办、专注、学习记录、本周进度必须真实工作；
- 本地数据刷新/重新进入后仍可靠保存；
- 能量/等级逻辑必须真实触发；
- 自定义目标必须动态计算；
- 总结页不能破坏原数据；
- 不接账号、服务器、真实日历或其他外部 API。

## 结果只记录

- 首版耗时；
- 修改1耗时；
- 修改2耗时；
- Challenge耗时；
- 是否出现故障；
- AI是否自修成功；
- 是否需要人工代码；
- 首版第一眼效果：强 / 中 / 弱；
- 最终试玩：通过 / 部分 / 失败；
- 发布/二维码：通过 / 未测 / 失败；
- Verdict：Strong Pass / Pass with Guardrails / Fail。

## Strong Pass 释放内容

通过后立即允许：

- 小学 L9 / L10 正式逐课教案；
- 初中 L5 / L6 正式逐课教案；
- 初中 L12 问题池加入 M5 工具轨道；
- 小学 / 初中 Final 项目菜单加入 M5；
- 对应教师示例作品与课堂物料生产。

M5 对当前课程解锁范围最大，因此结果回来后优先产品化。

## Fail 时

不要通过增加教师技术操作救回。

只做：

- 缩小首版功能；
- 减少本地状态和统计联动；
- 固定更稳定的“学习驾驶舱”统一起点；
- 把高级统计 / 等级 / 总结降到后续扩展；
- 重新跑最小验证。
