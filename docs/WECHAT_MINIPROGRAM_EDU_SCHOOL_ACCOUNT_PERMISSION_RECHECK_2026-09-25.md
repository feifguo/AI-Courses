## 1. 这次复核要回答什么

正式进入学校前，需要确认：

1. 教师能否直接创建学校；
2. 未认证学校是否能先开课；
3. 教师 / 超管能否创建学生账号；
4. 学生是否需要个人手机号；
5. 是否存在默认学生账号 / 小程序数量；
6. 学校认证后增加什么能力；
7. 我们的代理商能否管理多所学校；
8. 同一个课程方如何跨学校规模化交付。

# 3. 当前“账号创建”最具体的公开操作证据

目前公开搜索中，最具体的学校 / 学生账号操作说明仍来自 2025-04 的第三方操作记录，而不是腾讯正式帮助中心页面。

该记录称当时平台支持：

- 教师注册时选择“我是老师”；
- 教师以超管身份创建学校；
- 学校下管理老师和学生账号；
- 学校注册后即使未认证也可以先开展教学；
- 创建学校后默认获得一批学生账号；
- 教师 / 超管可新增学生；
- 新增教师 / 学生时自动分配小程序；
- 教师拥有自己的 APPID；
- 未认证学校存在一定小程序数量上限。

来源：

https://www.wcccwl.com/h-nd-430.html

该页面给出了非常具体的 UI 路径和截图，因此具有较高操作参考价值。

但必须明确：

> **它不是腾讯当前正式帮助文档，且发布时间是 2025-04。**

因此不能把页面中的“默认50个账号”“未认证上限500”等数字写成 2026-09 的永久官方规则。

# 4. 当前没有从官方公开资料确认的关键问题

本轮重新搜索后，仍未找到腾讯 / 微信公开帮助中心对下面问题给出足够具体的当前规则：

## 4.1 普通代理商是否可以长期创建和管理多所学校

没有找到公开官方说明可以支持：

> “一个课程代理商账号可以直接建立并集中管理多所学校。”

这仍然是项目的重要开放问题。

## 4.2 学校认证主体要求

公开材料不能充分确认：

- 必须由学校法人主体认证；
- 培训机构 / 企业能否认证为教学组织；
- 代理商能否代表学校完成认证；
- 非认证状态能持续使用哪些能力。

## 4.3 商业课程交付边界

平台面向师生免费开放，并不等于已经确认：

> 第三方商业课程公司可以无限制跨多校组织商业交付。

这需要当前账号界面 / 官方商务渠道确认。

## 4.4 学生账号当前默认数量与上限

2025 第三方记录中的数量不能直接当作 2026 当前规则。

## 4.5 批量创建学生账号

第三方记录当时称手动新增、批量新增需要进一步联系官方。

当前是否已有新的批量工具，公开官方资料没有确认。

# 6. 下一次真实账号核验不要泛测，直接做这 12 步

使用一个当前教师 / 超管真实账号：

### Step 1
进入账号首页，记录账号当前身份。

### Step 2
查看是否有：

> 创建学校 / 加入学校 / 学校管理

入口。

### Step 3
尝试创建一个测试学校 / 组织（如政策允许）。

记录：

- 要填什么；
- 是否要求资质；
- 是否要求认证后才能继续。

### Step 4
进入账号管理。

记录：

- 能否创建教师；
- 能否创建学生；
- 是否显示剩余额度 / 数量上限。

### Step 5
创建一个测试学生账号。

记录：

- 是否需要手机号；
- 是否需要微信绑定；
- 是否需要实名；
- 是否只需要账号 + 密码。

### Step 6
确认新学生是否自动获得项目 / 小程序空间。

### Step 7
查找：

> 批量添加 / 导入学生

功能。

如果没有，记录 UI 现状，不猜。

### Step 8
查看学校认证入口。

记录：

- 认证类型；
- 主体要求；
- 所需资料；
- 认证后增加哪些能力。

### Step 9
查看教师是否能加入第二个学校。

这是代理商多校交付的关键测试。

### Step 10
查看超管 / 管理员是否能切换多个学校。

### Step 11
查找平台关于：

- 商业使用；
- 服务机构；
- 合作伙伴；
- 多校管理；

的当前入口或说明。

### Step 12
把 UI 截图 / 结果写回 Repo。

不要只口头描述。

- 平台仍持续运营；
- 平台面向学校 / 师生；
- 有教师管理和学生创作体系；

- 商业课程公司的组织角色；

- 当前账号数量 / 上限；
- 当前批量导入；
- 跨校教师权限；
- 是否需要官方合作授权。

# 8. 当前结论

本轮公开信息复核没有发现需要推翻现有工具选择的新事实。

微信小程序教育平台仍然适合继续作为学生主要创作平台。

但是：

> **“单校教师教学可行”不能自动外推成“代理商多校商业交付已经解决”。**

因此这一项保持：

> **SCHOOL-NATIVE PLATFORM = YES**
>
> **MULTI-SCHOOL CHANNEL MODEL = UNVERIFIED**

正式首批多校签约前，必须完成一次当前真实 UI 的 12 步核验。

这项验证与课程内容开发、M3/M4/M5、教师整合页可以继续并行，不需要阻塞当前课程开发。
