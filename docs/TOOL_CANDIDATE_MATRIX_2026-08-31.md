# AI 原生创作工具候选矩阵

更新时间：2026-08-31
状态：SECOND-PASS SHORTLIST / 待真实课堂原型测试

本文件服务于 `docs/TOOL_AND_WOW_SCAN_2026-08-31.md` 与 `docs/SCHOOL_NATIVE_PLATFORM_SCAN_2026-08-31.md`。

目的不是找“最强开发工具”，而是找**最适合学校兴趣课、低门槛、高 Wow、可长期交付**的 AI 创作工具链。

## 0. 第二轮后的重要修正

第一轮主要从 AI 创作能力出发，优先看到秒哒、扣子、WorkBuddy 等通用平台。

第二轮进一步核查国内真实进校案例后，必须增加一个更高权重：

> **学生端是否为中小学教学原生设计，是否有学校/教师/学生账号、教学管理、作品管理和真实进校验证。**

因此当前不再使用单一总排名，而采用两层候选：

1. **学校基础设施 / 教育原生平台**；
2. **AI 创作引擎 / 通用 Builder**。

两层可以组合，但不能让课堂在多个工具之间频繁跳转。

# 1. P0 — SCHOOL-NATIVE / 小学高年级第一优先验证

## 1.1 微信小程序教育平台

定位判断：

> **当前最值得验证的“小学高年级正式课堂主环境”。**

### 已核实能力

腾讯官方/公开材料已确认：

- 专为中小学教学场景设计；
- 项目式人工智能学习实践平台；
- 学校/教师教学管理；
- 学生作品创作；
- 在线代码编辑、预览、发布；
- 云端存储与版本管理；
- 官方课程、任务、做课与学情分析；
- AI 助手 / AI 老师；
- AI 自然语言辅助创作；
- 文生图；
- 网页版教学工具；
- 作品广场与赛事闭环；
- 学生可制作真正的小程序，而不是模拟界面。

腾讯 2026-06 官方披露：近 8000 所学校、17,830 名教师、超过 87,000 名学生，超过 28.7 万个小程序作品，开发过程中 AI 使用累计超过 500 亿词元。

来源：
- https://www.tencent.com/zh-cn/young-creators-are-building-the-future-with-ai-and-mini-programs/
- https://www.tencent.com/zh-cn/wetech-for-education-awards-celebrate-innovative-hong-kong-youth/
- https://static.www.tencent.com/attachments/ssv/2025/tencent-ssv-report-2024.pdf
- https://static.www.tencent.com/uploads/2026/04/09/f6dbd30b3d8ca9c65f76f3d73b7da739.pdf

### 费用

微信公开课 2026 信息称平台面向师生免费提供“学 AI、用 AI、教 AI”的全流程基础教学能力。

来源（转载微信公开课信息）：
- https://www.ithome.com/0/918/811.htm

但商业课程开发方跨多校使用、AI调用限额、批量账号上限仍需真实账号和商务确认。

### 学校组织价值

公开学校案例已经出现：

- 学校统一向学生发放小程序教育平台账号；
- 比赛/活动结束后回收；
- 使用网页版工具；
- 不需要让学生临时注册消费级个人账号。

来源：
- https://gdapzx.cn/uploads/allimg/20251125/1-251125150445418.pdf

### 对课程的价值

特别适合：

- 真实英语学习小程序；
- 记忆/答题/闯关小游戏；
- 校园工具；
- 兴趣知识小程序；
- 项目式解决真实问题；
- Demo Day 手机扫码体验。

对家长而言，“孩子真的做了一个微信小程序”具有非常直观的产品感。

### 最大待验点

虽然 AI 辅助能力已经明确存在，但还不能从公开资料确认它是否达到秒哒那种：

> “一句完整自然语言 → 整个应用第一版 → 自然语言连续修改”

的成熟度。

因此必须真实测试：

- 10–15 分钟能否出现第一版；
- 不写代码能否做完整小游戏/学习工具；
- AI 是真正修改项目还是只回答“代码应该怎么写”；
- 普通教师不看代码能否救场。

状态：

> **P0 / SCHOOL-NATIVE FRONT-RUNNER / HANDS-ON REQUIRED**

# 2. P0 — AI CREATION ENGINE / 首轮必须做真实原型

## 2.1 百度秒哒 MIAODA

定位判断：**当前最接近“小学生/初中生用自然语言直接做应用”的国内通用候选。**

已核实能力：
- 官方定位为无代码应用开发平台；
- 无需编程背景，自然语言对话生成应用；
- 支持 H5、网站、小游戏、轻应用；
- 可由 AI 主动澄清需求；
- 生成后可继续用自然语言或 GUI 修改；
- 可在线预览；
- 可发布为公开链接；
- web/H5 可生成二维码；
- 非游戏类应用可通过秒哒官方微信小程序快速分享；
- 2026 V3.0 已加入 APP 生成、AI 自动质检、图片/PPT/视频等通用任务。

对课程的价值：
- 非常适合“英语学习平台 / 兴趣数字基地 / 学习驾驶舱 / 简单小游戏”；
- 学生几乎可以只做“描述—看结果—修改—分享”；
- 手机二维码展示对家长和学校特别友好；
- GUI 修改有助于避免老师被迫看代码救场。

风险：
- 快速开发、深度开发、质检、复制、发布等会消耗平台额度；
- 公开应用广场支持别人查看搭建过程并复制应用，因此**我们的课程底座、模板和核心示例不得公开上架应用广场**；
- 小学正式课堂仍需解决监护同意、组织账号、隐私和批量管理；
- 网站发布涉及域名备案时会增加复杂度，课堂优先 H5 / 平台公开链接 / 官方小程序。

费用与年龄、模型绑定详见：
- `docs/CLASSROOM_PLATFORM_ECONOMICS_AND_RISKS_2026-08-31.md`

未成年人：秒哒用户协议允许未满18岁用户在监护人监护、指导并获得同意的情况下使用；其隐私规则表明产品主要面向成年人，不满14岁需监护人同意。

## 2.2 扣子 / 扣子编程

定位判断：**最值得验证的“AI 应用 + 游戏 + 智能体”一体化候选，当前更偏初中。**

已核实能力：
- 云端 AI 开发环境；
- 无需写代码、无需搭环境；
- 用自然语言描述功能、界面、逻辑即可从零生成；
- Agent 自动规划、生成前后端、构建、预览、测试、迭代和部署；
- 官方明确列出网页互动游戏、业务系统、网站等场景；
- 可按需加入数据库、用户登录、AI 生成、联网搜索等内置集成；
- 团队版/企业版具备功能访问控制和空间资源权限。

对课程的价值：
- 第一阶段可做小游戏、互动网页；
- 第二阶段特别适合做“会 AI 的产品”，例如 AI 宠物、AI 博物馆馆长、AI 学习助手；
- 比纯网页生成器更容易自然进入“作品真的有 AI”这一能力跃迁。

风险：
- 编程任务、模型、联网、图像生成和托管都会消耗积分；
- 功能过强，学生容易不断加后端/登录/数据库导致复杂度失控；
- 当前公开协议存在对未成年人和 13 岁以下作品受众的额外限制，因此不作为小学高年级默认学生端，需专项合规确认。

费用、模型自由度与年龄问题详见：
- `docs/CLASSROOM_PLATFORM_ECONOMICS_AND_RISKS_2026-08-31.md`

官方来源：
- https://docs.coze.cn/guides_vibe_coding_web_app
- https://docs.coze.cn/cozespace_vibe_coding_web_app
- https://docs.coze.cn/cozespace_5uu7ba6t
- https://docs.coze.cn/

## 2.3 WorkBuddy / CodeBuddy

定位判断：**最适合验证“复杂外观、极轻底座”的个人工作台/轻应用路线。**

已核实能力：
- Agent 可生成网页并直接预览；
- WorkBuddy 提供 HTML + CSV 轻应用模式；
- 官方明确举例个人工作台、项目管理、任务看板、记账、经营工作台；
- HTML 页面可一键发布为在线网站；
- CodeBuddy 的 Preview 可自动渲染、选中组件并用自然语言修改，错误也可以直接发给 AI 自动修复。

对课程的价值：
- 最适合研究“看起来像复杂软件，实际上只是 HTML + CSV/localStorage”的高杠杆效果；
- 教师或课程开发方可以用它批量制作稳定底座；
- 学生可做学习驾驶舱、兴趣管理台、个人数字基地。

风险：
- 产品更像 Agent 工作台/代码助手，对小学生认知负担可能更高；
- 若暴露文件树、终端、代码等专业界面，会偏离课程定位；
- 优先作为课程研发方/教师底座生产工具，而不是小学默认学生端。

官方来源：
- https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Library/Lightweight-Publish
- https://www.codebuddy.ai/docs/zh/ide/User-guide/preview
- https://www.workbuddy.cn/privacy/

状态：

> **P0 MECHANISM TEST / TEACHER-R&D HIGH VALUE**

# 6. 首轮统一原型任务

不能让每个工具做不同作品，否则无法比较。

小学 P0 首轮：

- 微信小程序教育平台；
- 秒哒。

初中 P0 首轮：

- 微信小程序教育平台；
- 秒哒；
- 扣子编程。

WorkBuddy 作为相同任务的教师/R&D 对照组。

## T1 — 45分钟 Wow：个性化小游戏

要求：
- 学生主要输入自然语言；
- 10–15分钟内第一版能玩；
- 至少有角色/对象交互、得分、失败/胜利、声音或视觉反馈；
- 学生能修改主题、角色、规则和难度；
- 最终可通过二维码/链接/教育体验版展示；
- 教师不得靠手改代码完成救援。

## T2 — “复杂但不难”：学习驾驶舱 / 英语学习平台

要求：
- 课程/单词或知识卡；
- 今日任务；
- 测验；
- 得分和反馈；
- 进度；
- 数据只使用本地存储/平台简单数据，不接真实学校系统；
- 学生可明显个性化主题和规则。

## T3 — “它真的有 AI”：兴趣博物馆 / AI角色

要求：
- 有视觉页面；
- 有学生自己的主题内容；
- 能与参观者对话或回答问题则加分；
- 不允许为了 AI 对话让学生学习 API；
- 可通过手机体验。

## T4 — 视觉冲击测试：江南水乡互动场景

要求：
- 浏览器/小程序实时运行，不是预生成视频；
- 船/人物/镜头能动；
- 场景包含河流、建筑、桥、树木/灯笼等；
- 学生可一句话改变天气、时间、速度或加入任务。

T4 是上限测试，不预设进入正式课程；失败率、机器要求或教师救援成本过高即降级为教师演示/选做。

# 7. 统一评分维度

每个工具每个任务记录：

1. 从登录到开始创作的步骤数；
2. 首次可运行成果时间；
3. 学生需要输入的技术词汇数量；
4. 是否需要看到/编辑代码；
5. 第一次生成成功率；
6. 自然语言修改成功率；
7. 教师救援次数；
8. 单次救援是否需要技术知识；
9. 30人同时使用的账号/并发可行性；
10. 单生单课估算费用；
11. 作品是否可手机直接体验；
12. 是否能形成学生作品集；
13. 未成年人和学校组织条件；
14. 家长“这真是孩子做的？”冲击力；
15. 学生作品所有权感。

核心淘汰线：

> **如果普通教师必须频繁读代码/修代码，或学生前20分钟仍没有可见成果，则不适合作为小学主工具。**

# 8. 当前第二轮判断

## 小学高年级

不是简单排序，而是两个最重要候选的不同优势：

### 微信小程序教育平台

> **学校适配最强，AI-native 强度待实测。**

### 秒哒

> **AI-native 创作最直接，学校/未成年人适配待解决。**

小学真正的核心验证问题是：

> **微信教育平台能否在保持学校原生优势的同时，做到秒哒式的“自然语言快速做出完整作品”？**

若能，优先级极高。

若不能，则考虑：

> 教育原生平台作为正式课堂主环境 + 少量受控创作引擎作为 Wow 模块。

## 初中

更可能采用：

> 微信小程序教育平台 / 秒哒 / 扣子编程三者择优或分阶段使用。

最终工具定型必须基于真实账号、统一任务和课堂原型数据，而不是官方功能表。
