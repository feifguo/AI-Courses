# AI 原生创作工具候选矩阵

更新时间：2026-08-31
状态：FIRST-PASS SHORTLIST / 待真实课堂原型测试

本文件服务于 `docs/TOOL_AND_WOW_SCAN_2026-08-31.md`。目的不是找最强开发工具，而是找最适合学校兴趣课的低门槛 AI 创作工具。

## 1. 当前排序

### P0 — 首轮必须做真实原型

#### 1. 百度秒哒 MIAODA

定位判断：**当前最接近“小学生/初中生用自然语言直接做应用”的国内候选。**

已核实能力：
- 官方定位为无代码应用开发平台；
- 无需编程背景，自然语言对话生成应用；
- 支持 H5、网站、小游戏、轻应用；
- 可由 AI 主动澄清需求；
- 生成后可继续用自然语言或 GUI 修改；
- 可在线预览；
- 可发布为公开链接；
- web/H5 可生成二维码；
- 非游戏类应用可通过秒哒官方微信小程序快速分享；
- 2026 V3.0 已加入 APP 生成、AI 自动质检、图片/PPT/视频等通用任务。

对课程的价值：
- 非常适合“英语学习平台 / 兴趣数字基地 / 学习驾驶舱 / 简单小游戏”；
- 学生几乎可以只做“描述—看结果—修改—分享”；
- 手机二维码展示对家长和学校特别友好；
- GUI 修改有助于避免老师被迫看代码救场。

风险：
- 快速开发、深度开发、质检、复制、发布等会消耗平台额度；
- 公开应用广场支持别人查看搭建过程并复制应用，因此**我们的课程底座、模板和核心示例不得公开上架应用广场**；
- 学校正式使用前仍要验证并发、账号开通、课堂网络、未成年人监护同意和批量管理；
- 网站发布涉及域名备案时会增加复杂度，课堂优先 H5 / 平台公开链接 / 官方小程序。

未成年人：秒哒用户协议允许未满18岁用户在监护人监护、指导并获得同意的情况下使用。

#### 2. 扣子 / 扣子编程

定位判断：**最值得验证的“AI 应用 + 游戏 + 智能体”一体化候选。**

已核实能力：
- 云端 AI 开发环境；
- 无需写代码、无需搭环境；
- 用自然语言描述功能、界面、逻辑即可从零生成；
- Agent 自动规划、生成前后端、构建、预览、测试、迭代和部署；
- 官方明确列出网页互动游戏、业务系统、网站等场景；
- 可按需加入数据库、用户登录、AI 生成、联网搜索等内置集成；
- 扣子本体也已把编程能力封装成普通 Agent，可以从一句想法开始生成代码、预览并上线；
- 团队版/企业版具备功能访问控制和空间资源权限。

对课程的价值：
- 第一阶段可做小游戏、互动网页；
- 第二阶段非常适合做“会 AI 的产品”，例如 AI 宠物、AI 博物馆馆长、AI 学习助手；
- 比纯网页生成器更容易自然进入“作品真的有 AI”这一能力跃迁。

风险：
- 编程任务、模型、联网、图像生成和托管都会消耗积分；
- 功能过强，学生容易不断加后端/登录/数据库导致复杂度失控；
- 未成年人和学校集体账号规则需要专项确认后才能定为学生主工具。

官方来源：
- https://docs.coze.cn/guides_vibe_coding_web_app
- https://docs.coze.cn/cozespace_vibe_coding_web_app
- https://docs.coze.cn/cozespace_5uu7ba6t
- https://docs.coze.cn/

#### 3. WorkBuddy / CodeBuddy

定位判断：**最适合验证“复杂外观、极轻底座”的个人工作台/轻应用路线。**

已核实能力：
- Agent 可生成网页并直接预览；
- WorkBuddy 提供 HTML + CSV 轻应用模式；
- 官方明确举例个人工作台、项目管理、任务看板、记账、经营工作台；
- HTML 页面可一键发布为在线网站；
- CodeBuddy 的 Preview 可自动渲染、选中组件并用自然语言修改，错误也可以直接发给 AI 自动修复。

对课程的价值：
- 最适合研究“看起来像复杂软件，实际上只是 HTML + CSV/localStorage”的高杠杆效果；
- 教师或课程开发方可以先用它批量制作稳定底座；
- 学生可做学习驾驶舱、兴趣管理台、个人数字基地。

风险：
- 相比秒哒，产品更像 Agent 工作台/代码助手，对小学生界面认知负担可能更高；
- 课堂使用时若暴露文件树、终端、代码等专业界面，会偏离课程定位；
- 应优先验证 Work 模式/轻应用，而不是让学生进入 IDE；
- 未成年人使用需要监护人同意；不满14岁还有儿童个人信息保护要求。

官方来源：

- https://www.codebuddy.ai/docs/zh/ide/User-guide/preview

### P1 — 有明确价值，但不是小学第一主工具

#### 4. TraeWork

优势：
- 网页版无需安装；
- Work 模式明确面向非开发用户；
- 可以让 Agent 完成任务，浏览器直接预览 Web 产物；
- 对页面元素可以点选后评论给 AI 修改；
- 本地/云端双模式适合教师开发和复杂项目。

判断：
- 很适合课程开发团队、教师培训和初中较高自主度项目；
- 但整体仍偏通用 Agent/开发工作台，不是小学高年级首选学生界面；
- 未成年人账户与学校场景要额外确认，企业版隐私政策明确服务主要面向成年人或企业，未成年人需监护人同意。

来源：
- https://docs.trae.cn/work_trae-work-web-and-desktop-quickstart
- https://docs.trae.cn/work_what-is-trae-work
- https://docs.trae.cn/enterprise_privacy-policy-for-trae-enterprise

#### 5. 腾讯元器

定位判断：**不是通用游戏/网页生成器，但非常适合“会对话的 AI 作品”。**

已核实能力：
- 官方定位零代码、零基础创建智能体；
- 支持知识库、工作流、多 Agent；
- 可发布 Web 体验链接和二维码；
- 可发布至腾讯生态渠道；
- 有 API，可嵌入其他作品，但正式课程第一阶段不应让学生碰 API。

对课程的价值：
- AI 博物馆馆长；
- AI 历史人物/虚构角色；
- AI 兴趣专家；
- AI 校园导览员。

最佳用法不是单独作为整学期工具，而是作为“作品第一次真正会对话”的能力跃迁模块。

来源：
- https://yuanqi.tencent.com/guide/yuanqi-introduction
- https://yuanqi.tencent.com/guide/agent-build-first-agent
- https://yuanqi.tencent.com/guide/share-agent

### P2 — 能力上限/海外产品标杆

#### Replit Agent
自然语言从想法到完整 Web/移动应用，直接预览、迭代、发布，零编程经验可用。适合作为我们判断行业能力上限的标杆，不应成为国内学校首要依赖。

来源：https://replit.com/products/agent

#### Bolt
自然语言生成完整应用并直接发布，官方强调零代码和分钟级成品。适合作为“极简 Vibe Coding”标杆。

来源：https://bolt.new/use-cases/ai-app-builder

#### Canva Code 2.0
一句对话生成网站、App、互动体验，并能像 Canva 设计一样继续可视化编辑；2026 已提供模板与 HTML 导入。对低龄视觉化创作非常有启发，但中国学校账号、网络和实际可用性需另验。

来源：https://www.canva.com/newsroom/news/Canva-Code/

## 2. 首轮统一原型任务

不要让每个工具做不同作品，否则无法比较。首轮用同一组任务：

### T1 — 45分钟 Wow：个性化小游戏
要求：
- 学生只输入自然语言；
- 10–15分钟内第一版能玩；
- 至少有角色移动、得分、失败/胜利、声音或视觉反馈；
- 学生能修改主题、角色、规则和难度；
- 最终可通过二维码/链接展示。

### T2 — “复杂但不难”：学习驾驶舱
要求：
- 课程表；
- 今日待办；
- 番茄钟；
- 阅读/学习记录；
- 本周进度；
- 数据只使用本地存储/CSV/平台简单数据，不接真实学校系统。

### T3 — “它真的有 AI”：兴趣博物馆/AI角色
要求：
- 有视觉页面；
- 有学生自己的主题内容；
- 能与参观者对话或回答问题；
- 可以公开链接/二维码体验。

### T4 — 视觉冲击测试：江南水乡互动场景
要求：
- 浏览器实时运行，不是预生成视频；
- 船/人物/镜头能动；
- 场景中至少有河流、建筑、桥、树木/灯笼等；
- 学生可用一句话改变天气、时间、船速或加入任务。

注意：T4 是上限测试，不预设一定进入正式课程。如果失败率、机器要求或教师救援成本过高，应降级为教师演示/竞赛选做，而不是为了“3D高级”破坏课程稳定性。

## 3. 当前第一判断

若只看“进入中国学校的可能性”而不是功能上限：

1. **秒哒：最优先做学生端原型；**
2. **扣子编程：最优先验证 AI 应用和互动游戏；**
3. **WorkBuddy：最优先验证工作台/轻应用机制，也适合课程开发方制作底座；**
4. **腾讯元器：最优先验证 AI 对话角色模块；**
5. **TraeWork：优先用于课程研发、教师端和初中扩展，不先作为小学主工具。**

这只是 FIRST-PASS，不等于工具定型。最终必须按真实完成率、现场失败率、教师救援时间、账号成本、分享效果和未成年人使用条件重新排序。
