### 评分参考

**1分**：基本无法独立完成，需要老师持续给答案。

**3分**：在教师追问/脚手架下能够完成。

**5分**：能自主提出、判断、修改，并解释为什么这样设计。

## D. 教师介入记录

| 时间 | 学生 | 学生卡在哪里 | 类型 T1–T6 | 教师说/做了什么 | 学生之后能否自己继续 |
|---|---|---|---|---|---|
| | | | | | |

介入类型：

- **T1 创意启动**：不知道做什么；
- **T2 表达澄清**：知道想法但说不清楚；
- **T3 任务拆解**：一次要求太多，需要拆分；
- **T4 判断/验证提醒**：相信 AI 已完成但未试玩；
- **T5 操作帮助**：按钮、预览、刷新等界面操作；
- **T6 技术救援**：必须看代码/配置/技术人员介入。

本轮最重要的是统计：

> 教师大量时间到底花在哪一类？

如果主要是 T2/T3/T4，说明课程真正需要训练的是 AI 协作能力。

如果大量是 T5/T6，才说明工具/操作仍然是主要负担。
