# 课程就绪图 V0.1

更新时间：2026-09-01
状态：ACTIVE IMPLEMENTATION MAP

## 1. 目的

M1 游戏母版和 M2 学习平台母版已经真实 Known-Good，M3/M4/M5 尚待验证。

因此不应出现两种错误：

1. 因为 M3/M4/M5 未验证，就让整套课程研发全部停住；
2. 反过来把依赖 M3/M4/M5 的课写成已经可以正式交付。

本文件把当前课次分为：

- **READY FOR LESSON PRODUCTIZATION**：底层母版已验证，可以继续做教师手册、学生任务卡、FALLBACK、Showcase；
- **CONDITIONAL READY**：教学机制本身可开发，但完整课型/项目菜单仍依赖待验证母版；
- **PENDING MOTHER VALIDATION**：应先等对应母版实测，不宜完整教案化。

# 5. 对上线节奏的意义

即使 M3/M4/M5 尚未验证，我们已经拥有足够的 Known-Good 底座做：

- Wow Demo；
- 第一阶段游戏课；
- 学习产品课；
- 初中产品方法课；
- 发布/展示课。

因此项目当前不是“被测试阻塞”，而是：

> **已验证部分继续产品化，未验证母版只阻塞依赖它们的具体课次。**

这能最大程度缩短进入学校的时间，同时不把未验证能力伪装成已完成事实。
