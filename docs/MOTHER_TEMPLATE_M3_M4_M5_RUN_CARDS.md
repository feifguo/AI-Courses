# M3 — 互动故事 / 分支世界

## 首版

> 帮我做一个适合小学高年级玩的互动冒险故事微信小程序，主题是“恐龙岛逃生”。不要让我写代码，请直接生成可以运行和预览的完整小程序。要有开场页，主角醒来后发现自己在恐龙岛。故事至少有3次玩家选择，每次选择进入不同情节，最终至少有3种明显不同的结局：成功逃离、被困岛上、发现隐藏研究基地。页面要有角色、场景视觉、明显选择按钮，并有简单动画或反馈。玩家可以重新开始探索其他结局。界面要有冒险感但适合小学生。

记录：首次生成耗时；是否一次可玩；是否有真实分支；是否达到展示线。

## 修改1

> 增加“勇气值”和“补给”两个状态。不同选择会增加或减少它们，部分选择只有达到一定勇气值或拥有补给时才能出现。请保持原来的故事和3种结局，并确保状态变化在页面上能看见。

## 修改2

> 把主角改成由玩家自己输入名字，并让玩家从“探险家、科学家、摄影师”三个身份中选择一个。不同身份至少有一次不同的专属选择。

## Challenge

> 增加一个隐藏结局，但不要直接告诉玩家怎么触发。需要玩家在前面的选择中收集到两个线索以后，最终才会出现隐藏入口。

### M3 快速判定

Strong Pass 至少满足：
- 首版已展示级；
- 分支是真的，不是假按钮；
- 状态修改能影响条件；
- 输入/身份个性化成功；
- Challenge 不破坏原故事；
- 全程不用人工代码。

# M4 — 兴趣馆 / 知识产品

## 首版

> 帮我做一个适合小学高年级的“恐龙探索博物馆”微信小程序。不要让我写代码，请直接生成可以运行和预览的完整小程序。首页要像真正的数字博物馆，有“肉食恐龙、植食恐龙、飞行爬行动物、化石发现”四个展区。每个展区至少有3个展品卡片，点进去可以看到名称、时代、特点和一条有趣事实。增加“我喜欢的展品”收藏功能，并有一个“恐龙挑战”入口，里面有10道四选一题、积分和通关页。界面要有博物馆/探险感，视觉完整，不要只是文字列表。所有数据放本地，不需要登录或服务器。

记录：首次生成耗时；首版是否像完整产品；收藏/挑战是否真的工作。

## 修改1

> 增加一个“我的探索进度”，显示4个展区各自看过多少展品，以及总探索百分比。看过的展品要有明显标记。仍然只用本地数据。

## 修改2

> 增加一个“我的新展区”，让使用者可以自己输入展区名称，再新增3个展品，每个展品输入名称、简介和一个有趣事实。保存以后，新展区要和原来的展区一样可以浏览，也计入探索进度。只用本地存储。

## Challenge

> 增加一个隐藏展品和“探索大师”徽章：只有用户看过至少80%的展品并完成知识挑战后才出现。不要破坏原来的收藏和进度功能。

### M4 快速判定

Strong Pass 至少满足：
- 首版不是文字堆砌；
- 4展区/详情/收藏/挑战都工作；
- 浏览记录能进进度；
- 自定义展区能保存并参与进度；
- Challenge 条件真实生效；
- 全程不用人工代码。

# M5 — 工作台 / 记录 / 校园工具

## 首版

> 帮我做一个适合小学高年级和初中生使用的“我的学习驾驶舱”微信小程序。不要让我写代码，请直接生成可以运行和预览的完整小程序。首页要像一个真正的个人学习控制台，显示今天待办、今日专注时间、本周完成任务数、连续学习天数。功能包括：1）待办任务，可新增、完成、删除；2）番茄专注，可开始25分钟专注并记录完成次数；3）阅读/学习记录，输入今天学了什么、花了多久；4）本周进度，用简单图表或进度条展示每天完成任务数量和专注次数。界面要像现代App仪表盘，有明显卡片、状态和进度，不要像普通表单。所有数据只保存在本地，不需要账号、服务器或真实日历接口。

记录：首次生成耗时；是否第一眼像产品；刷新后数据是否还在。

## 修改1

> 增加“学习能量”和“等级”。每完成一个任务获得10点能量，每完成一次专注获得20点。能量达到100自动升级，并出现明显但不过度的升级动画。首页显示当前等级和升级进度。

## 修改2

> 增加“我的目标”，让使用者自己设置一个本周目标，例如“完成5次专注”或“读书120分钟”，首页显示目标进度。目标和进度都只保存在本地。

## Challenge

> 增加“本周总结”页面，自动汇总本周完成任务数、总专注时间、学习记录次数、目标完成度，并给出一个视觉化总结卡。不要接任何外部API。

### M5 快速判定

Strong Pass 至少满足：
- 首版明显像现代工具；
- 待办、专注、记录、本周进度都工作；
- 本地数据可靠保存；
- 能量/等级逻辑工作；
- 自定义目标能动态计算；
- 总结页不破坏原数据；
- 全程不用人工代码。
