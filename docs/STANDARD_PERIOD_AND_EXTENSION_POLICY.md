# 标准课时与延长拓展政策

更新时间：2026-09-01
状态：CONFIRMED / HARD PRODUCT CONSTRAINT

## 1. 基准课时

依据《义务教育课程方案（2022年版）》及多省课程实施办法：

- 小学标准课时：40 分钟；
- 初中标准课时：45 分钟；
- 学校可在保证总时长前提下采用弹性课时、长短课或集中安排。

参考：
- 教育部《义务教育课程方案（2022年版）》：小学每课时按40分钟计算，初中每课时按45分钟计算；
- 湖南、湖北、辽宁、广东等省级实施办法均沿用该标准，并允许学校根据课程性质灵活确定具体节长。

本项目因此不再把 45–60 分钟作为默认“标准单课时”。

## 2. 核心原则：主作品必须早于标准课时完成

课程设计不是追求“刚好40/45分钟做完”。

正式要求：

> **展示级 BASE 成品必须在标准课时结束前明显完成，并给课堂留下试玩、收口、恢复和展示缓冲。**

建议设计目标：

### 小学高年级

- 标准课时：40 分钟；
- BASE/FALLBACK 展示级成品目标：约 25–30 分钟内完成；
- 30–40 分钟：试玩、检查、统一收口、二维码/展示、或进入第一层拓展。

### 初中

- 标准课时：45 分钟；
- BASE/FALLBACK 展示级成品目标：约 30–35 分钟内完成；
- 35–45 分钟：测试、修复、用户反馈、版本收口、或进入第一层拓展。

这些不是机械到分钟的教学口令，而是课程产品的时间预算红线。

如果 BASE 只能在 40/45 分钟临近结束时完成，说明项目没有留下真实课堂所需的缓冲，不应直接作为正式标准课。

## 3. 三层时间结构

每节核心课统一设计三层：

### TIER 1 — DISPLAY-SAFE BASE

必须在“小于标准课时”的时间内完成。

特点：
- 低能力学生也能完成；
- 使用稳定母版、半结构化任务和菜单；
- 有明显视觉和交互效果；
- 可正常试玩；
- 可分享/展示；
- 即使课堂此时突然结束，也已经有拿得出手的作品。

### TIER 2 — STANDARD PERIOD DEPTH

利用标准课时剩余时间完成：
- 试玩；
- 找一个问题；
- 做一次有意义的修改；
- 同伴反馈；
- 修复；
- 作品命名、截图、二维码或简单展示。

这层承担课程主要的能力暗线。

### TIER 3 — EXTENSION / OPEN CREATION

当学校提供 50、60、90 分钟、双课时、社团课或课后服务时，额外时间全部用于：
- 功能挑战；
- 视觉增强；
- 新规则；
- 新页面/新模式；
- 用户体验优化；
- 完全自定义创意；
- 同伴试玩与二次迭代；
- 高能力学生自由拓展。

**延长时间绝不能成为完成 BASE 的必要条件。**

## 4. AI 原生课程的时间弹性优势

传统课程常见问题是快学生提前完成后只能等待，或老师被迫额外准备统一“加题”。

AI 原生创造课应利用一个天然优势：

> **最低完成线固定，最高创造上限不封顶。**

完成 BASE 后，学生可以自然进入：

> “我还想让它……”

教师不必预判所有可能的创意，只需要提供：

- Challenge Pool；
- 作品增强菜单；
- 开放创作提示；
- 安全与范围边界。

学生有自己的想法时直接自由发挥；没有想法时从挑战池选择。

## 5. 每节课必须配套 Challenge Pool

每个核心项目至少准备以下挑战类别中的若干项：

1. **规则挑战**：增加倒计时、连击、生命值、Boss、随机事件等；
2. **视觉挑战**：动画、主题切换、奖励效果、角色状态等；
3. **产品挑战**：增加页面、模式、记录、进度、个性化设置；
4. **用户体验挑战**：让别人更容易理解、更好玩、更顺手；
5. **内容挑战**：换成自己的兴趣、学科、校园、生活主题；
6. **开放挑战**：完全由学生提出“我还想让它……”。

挑战池不是主线要求，不允许因为挑战做不完影响基础学生的课程成功感。

## 6. 对不同课型的适配

### 40分钟小学标准课

必须完整成立：
- 快速进入；
- BASE完成；
- 至少一次试玩；
- 至少一个学生选择；
- 能展示。

### 45分钟初中标准课

必须完整成立，并尽量多一个：
- 用户/规则判断；
- 一次修改；
- 简单版本思维。

### 60分钟兴趣/社团课

不重新设计另一门课。

采用：
> 标准课核心 + 15–20分钟 Challenge/自由创作。

### 80–90分钟双课时/集中活动

采用：
> 标准课核心 + 深度拓展 + 同伴试玩/用户反馈 + 第二轮迭代 + 展示。

长课时应该显著增加作品差异度和学生所有权，而不是把基础流程拉长。

## 7. 教师课堂管理意义

时间策略同时也是教师负担策略。

老师必须知道两个时间点：

### BASE DEADLINE

到该时间，大多数学生必须已经拥有展示级作品。

未达到者立即触发：
- 稳定母版；
- 半成品；
- 功能降级；
- 统一修复；
- 必要时教师局部协助。

不允许学生把整节课耗在一个无法完成的高级功能上。

### OPEN CREATION START

已经完成 BASE 的学生无需等待全班，立即进入 Challenge / 自由创作。

因此同一课堂可以同时存在：
- 弱学生在安全完成；
- 普通学生在深化；
- 强学生在自由发挥。

## 8. 课程验收红线

任何正式课若出现以下情况，应重新设计：

- 小学 BASE 通常需要接近40分钟才能完成；
- 初中 BASE 通常需要接近45分钟才能完成；
- 延长到60分钟才有完整作品；
- 快学生完成后只能等待；
- Challenge 需要老师逐个发题；
- 低能力学生为了做Challenge反而失去保底成品；
- 没有时间进行至少一次真实试玩。

## 9. 一句话原则

> **标准课时之前先把成果锁住；标准课时以内把学习做实；标准课时之外把想象力放开。**

以及：

> **40分钟能完整交付，60分钟不水，90分钟仍然有创造空间。**
