## 一、总体策略

接下来不采用“先把一件事全部做完，再做下一件”的串行方式。

采用六条并行线：

1. 课程结构 V0.4 收紧；
2. M3 / M4 / M5 真实验证；
3. 已有 25 节课升级为新手教师可用内容；
4. 实际课堂物料生产；
5. Teacher Portal 课程控制层；
6. 持续走课与验收。

核心原则：

> **已稳定的内容立即产品化；待验证的底座单独验证；验证通过一个，就释放对应课程，不等全部完成。**

同时：

> **研发资料可以细碎，最终教师使用界面必须整合。**

# 二、Lane A：课程结构 V0.4

目标：先解决“学生自由度过早、教师难以统一带班”的结构性问题。

立即处理：

- 初中 L1：从 M1/M2 二选一改为统一起点；
- 小学 L9：工具类任务固定统一起点；
- 初中 L5：待 M5 验证后固定统一工具起点；
- 初中 L12：问题池与成熟产品轨道绑定；
- 小学 L13 / 初中 L13：Final 只能从成熟产品轨道起步，再逐渐开放；
- 全课程写入“先同构，后分化；先完成，后创造”。

完成标准：

- 所有新建产品课都有明确统一起点；
- 学生自由主要先发生在主题、内容、视觉、已验证功能菜单；
- 自由架构只在完成稳定版本后开放；
- 课堂不要求老师同时理解几十种完全不同的软件架构。

本线不等待 M3/M4/M5，但依赖它们的具体功能暂不写死。

# 四、Lane C：已有 25 节课“教师化”

目标：把现有逐课脚本从研发稿升级为真正的新手教师可执行内容。

本线现在立即开始，不等待 M3/M4/M5。

先做四节端到端样板：

1. 小学 L1：创作型课；
2. 小学 L15：测试 / 发布型课；
3. 初中 L3：规则 / 逻辑型课；
4. 初中 L9：AI判断 / 认知型课。

四节样板要覆盖不同课程形态，先把最终标准跑通。

每节教师版必须回答：

- 今天学生最终做成什么；
- 上课前老师准备什么；
- 开场怎么说；
- 每个时间段老师做什么；
- 学生做什么；
- 到什么时间应做到什么；
- 学生卡住时怎么办；
- 多人同时卡住怎么办；
- 做得快的学生做什么；
- 下课前如何收口；
- 老师课后只记录什么。

教师版不出现：

- BASE；
- FALLBACK；
- Recovery；
- Challenge；
- DISPLAY-SAFE；
- Known-Good；

等研发语言作为主要表达。

四节样板通过后，再批量升级剩余已有 21 节。

# 五、Lane D：实际课堂物料生产

目标：从“有教案”进入“真的可以上课”。

本线与 Lane C 流水线并行。

每节内容一旦教师版稳定，就立即进入物料生产，不等 25 节全部写完。

主要物料：

## 教师课堂材料

- 本节课堂 PPT / 投屏页；
- 本节示例作品；
- 必要的 Before / After 示例；
- 必要的错误示例；
- 教师速查信息。

## 学生材料

- 本节任务页；
- 本节检查页；
- 必要的主题 / 规则选择内容；
- 本节作品提交信息。

## 特殊课程材料

事实核查课：

- 教师预选来源；
- 待核查事实；
- 错误 AI 示例；
- 标准修改前后案例。

用户测试课：

- 测试任务；
- 反馈记录格式。

发布课：

- 作品卡；
- 二维码展示格式；
- 发布检查。

注意：

> 开发阶段可以分别保存这些源文件，但最终教师在 Portal 中看到的是一个整合页面，不需要自己找多个文件。

# 六、Lane E：Teacher Portal 课程控制层

本线与内容开发并行，但不主导课程设计。

先只开发最小控制层：

- 教师身份；
- 代理商 / 学校 / 班级绑定；
- 当前课在线授权；
- 单课整合教学页；
- 课堂投屏；
- 学生本节任务页；
- 作品提交；
- 课后记录；
- 课程方后台；
- 平台故障时由课程方人工“应急授权本课”。

不做：

- 自助下载教案；
- 提前缓存教案；
- 完整学期教师手册下载；
- 重做微信小程序生成工具；
- 重型 LMS。

Lane E 的内容接口以 Lane C 四节样板为第一批真实数据。

先用四节样板证明：

> 同一份课程源内容可以稳定生成教师页面、投屏页面和学生任务页面。

再铺全课程。

# 七、Lane F：走课、验收与返修

这条线不是最后才开始，而是跟着每节课走。

每完成一节“教师版 + 物料”，立即进入一次内部走课。

第一轮优先走四节样板：

- 小学 L1；
- 小学 L15；
- 初中 L3；
- 初中 L9。

检查：

- 老师是否只看最终教师页面就能上；
- 是否还需要回研发文档找答案；
- 课堂语言是否自然；
- 时间是否合理；
- 学生是否过早分叉；
- 是否出现大量个别救火；
- 投屏内容是否够用；
- 学生任务是否过长；
- 快学生是否有明确下一步；
- 下课是否能稳定收口。

不通过就回 Lane C / D 修，不把问题留给教师。

M3/M4/M5 对应课程一旦补齐，也立即进入同样验收。

# 九、不要按“32节全部先做同一步”的方式生产

不采用：

> 32节先全部写教案 → 再全部做PPT → 再全部做学生任务 → 最后一起测试。

这样最后才发现模板不好会大面积返工。

采用流水线：

> **四节样板完整跑通 → 固定标准 → 批量铺已有稳定课程 → 母版通过一个就接入一批课程。**

例如：

小学 L1 教师版完成  
→ 马上做 L1 PPT / 学生页  
→ 马上走课  
→ 修正模板  
→ 用修正后的模板生产其他课。
