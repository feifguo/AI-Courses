本协议用于实际比较：

### 小学高年级 P0

---

# 2. 执行原则

## 2.1 模拟真实教师，而不是技术人员

执行人不得主动手写代码修复项目。

允许：
- 自然语言输入；
- 平台提供的 GUI 编辑；
- 平台自带 AI 修复；
- 使用课程预设模板；
- 普通教师看得懂的按钮操作。

不允许为了“让测试通过”而：
- 打开终端手修依赖；
- 自己写 JavaScript/Python；
- 修改配置文件；
- 查开发文档后手工排障。

一旦必须这样做，应记录为 **TECHNICAL RESCUE REQUIRED**。

## 2.2 时间上限

每个任务：
- 第一个可见成果目标：10 分钟；
- 第一个可运行版本淘汰线：15 分钟；
- 完整课堂版本上限：45 分钟。

如果普通执行人 20 分钟仍无可展示成果，不适合作为小学 Wow 主工具。

## 2.3 不追求完全相同技术实现

比较的是学生最终体验：

> 我提出想法 → AI做第一版 → 我判断 → 我继续修改 → 作品明显变成我的 → 别人可以体验。

不是比较代码质量。

# 3. Benchmark T1 — 记忆力翻牌 / 个性化小游戏

选择这个任务的原因：

- 腾讯 2026-07 培训已公开演示微信小程序教育平台用 AI 约 5 分钟生成“记忆力翻牌”小游戏，可作为复现基准；
- 规则简单但足够体现完整产品：界面、状态、交互、胜负、反馈；
- 很容易个性化；
- 小学生能够理解并试玩。

公开证据来源：
- https://finance.sina.com.cn/stock/t/2026-07-16/doc-inihzmms7652963.shtml

## T1-A 第一轮 Prompt

> 帮我做一个可以直接玩的“记忆力翻牌”小游戏。屏幕上有 12 张背面朝上的卡片，每两张是一对。点击卡片会翻开，连续翻开的两张如果相同就保持正面，不相同就过一会自动翻回去。全部配对成功后显示“挑战成功”，并显示用了多少次翻牌。界面要适合小学生，清楚、好看、有明显反馈。请直接帮我做出可以运行的第一版，不要先给我讲编程知识。

记录：
- 从提交到第一版可运行时间；
- 是否需要用户做技术选择；
- 是否一次运行成功；
- 是否出现明显 bug。

## T1-B 个性化 Prompt

> 我不想要普通图案。把主题改成“我的太空探险”，6 对卡片分别是火箭、宇航员、月球、土星、空间站、外星人。背景改成太空风格。每配对成功一组就加 10 分，并出现一个短暂的星星动画。

记录：
- 是否真的修改原项目；
- 是否破坏原功能；
- 是否需要重新生成整个作品；
- 视觉变化是否明显。

## T1-C 规则修改 Prompt

> 再增加一个挑战模式：60 秒倒计时。60 秒内全部配对就胜利；时间到了还没完成就显示“再试一次”。游戏开始前让我选择“普通模式”或“挑战模式”。

记录：
- AI能否理解新增状态和规则；
- 是否出现计时器 bug；
- 普通教师是否可以只靠继续说话修复。

## T1-D 学生所有权检查

执行人应能够回答：
- 我为什么选这个主题；
- AI第一版是什么样；
- 我改了哪三件事；
- 哪一次修改没有成功；
- 我最后为什么保留这个版本。

# 4. Benchmark T2 — 五年级英语学习平台

这是采购方真实“Wow”参照：五年级学生用 AI 做出英语学习平台。

## T2-A 第一轮 Prompt

> 帮我做一个给小学五年级学生用的英语单词学习工具。首页有“开始学习”“单词闯关”“我的成绩”三个入口。先内置 20 个常见英语单词，每个单词有英文、中文意思和一个简单例句。单词闯关每次随机出一道四选一题，答对加 10 分，答错告诉我正确答案并给一句鼓励。做成一个真正可以点击使用的学习产品，不要只做静态页面，也不要先给我讲代码。

## T2-B 个性化 Prompt

> 把整个产品主题改成“太空英语学院”。积分叫“能量值”。连续答对 5 题进入“超级宇航员模式”，界面出现明显变化，并额外奖励 30 能量值。

## T2-C 学习设计修改

> 我觉得答错以后直接告诉答案太简单。改成第一次答错时先给一个提示，再答错才显示正确答案。成绩页显示总答题数、正确率和最高连续答对次数。

验收：
- 是否真的有状态和统计；
- 不使用真实登录/数据库也能完成；
- 家长手机是否能直接体验；
- 是否看起来像一个“产品”而不是作业网页。

# 5. Benchmark T3 — AI 兴趣博物馆

## T3-A 第一轮 Prompt

> 帮我做一个“恐龙博物馆”互动作品。首页像一个真正的博物馆，有霸王龙、三角龙、迅猛龙、剑龙四个展区。点击每个展区可以看到图片位置、名字、生活年代、吃什么、一个有趣知识。要有“今日挑战”小测验，并记录得分。先做出可以直接体验的完整第一版。

## T3-B AI 馆长

> 增加一个“AI馆长”入口。参观者可以问恐龙相关问题，馆长用适合小学生理解的方式回答。如果平台本身能直接加 AI 对话，请用平台最简单的方式完成；如果必须让我自己写 API、申请密钥或配置服务器，就先停止并告诉我。

这里特别记录：
- 能否零代码加入 AI；
- 模型是否平台内置；
- 是否产生额外账号/密钥/费用；
- 是否适合未成年人作品公开给家长体验。

# 6. Benchmark T4 — 江南水乡互动世界（上限测试）

Prompt：

> 做一个可以在浏览器或小程序里实时运行的江南水乡互动场景，不是预生成视频。画面从一条小船上的第一人称或跟随视角开始，小船沿河缓慢前进。两侧有白墙黑瓦、水边树木、红灯笼和至少两座石桥，水面有简单倒影或波纹。用户可以控制船左右移动。经过第二座桥后天色逐渐变成傍晚。请优先保证能运行和连续流畅，不要要求我自己写代码。

第二轮：

> 加一个小任务：沿途找到 3 只躲在河边的猫，每找到一只就显示“发现 1/3”，找到全部后出现烟花或灯笼亮起的庆祝效果。

判定：
- 只用于测试视觉上限；
- 若需要高性能电脑、复杂代码救援、外部 CDN 不稳定，则不进入小学正式主课；
- 可以保留为教师演示、科技节展示或初中选做。

# 7. 评分表

每个平台每个任务 0–5 分：

| 维度 | 5分含义 |
|---|---|
| 登录/账号 | 教师预建账号，学生几乎零摩擦进入 |
| 首版速度 | 10分钟内稳定出现可运行作品 |
| 自然语言生成 | 一段普通中文就能形成完整第一版 |
| 自然语言修改 | 可以直接修改已有作品且成功率高 |
| 不看代码 | 全程无需学生/老师理解代码 |
| 失败恢复 | AI自己可修，普通老师一句话能救 |
| 视觉完成度 | 不额外设计也有明显成品感 |
| 功能完成度 | 真正会工作，不是静态展示 |
| 个性化 | 学生修改后作品差异明显 |
| 分享 | 手机扫码/链接立即体验 |
| 学校管理 | 班级、学生、作品、教师管理友好 |
| 未成年人 | 教育原生/边界清楚/账号可管理 |
| 成本 | 30人课堂长期预算易控制 |
| 教师负担 | 普通培训教师可独立带班 |
| Wow | 家长会明显产生“这真是孩子做的？”反应 |

### 加权建议

小学高年级：
- 不看代码 × 2；
- 学校管理 × 2；
- 未成年人 × 2；
- 教师负担 × 2；
- Wow × 2。

初中：
- 自然语言修改 × 2；
- 功能完成度 × 2；
- 个性化 × 2；
- Wow × 2。

# 8. 淘汰条件

出现任一项，默认不作为小学正式主工具：

1. 学生必须个人手机号/实名现场注册且无法学校统一管理；
2. 普通教师需要读代码才能频繁救场；
3. 第一版经常 20 分钟仍无法运行；
4. AI主要是“告诉你怎么写代码”，而不是直接替你完成修改；
5. 30人同时使用存在明显额度/并发不可控；
6. 作品无法方便地让家长手机体验；
7. 未成年人条款无法形成学校规模化合规路径；
8. 一节课大量时间用在配置、登录、发布而不是创造。
