# Internal R&D Assets

状态：INTERNAL / DO NOT DISTRIBUTE TO CHANNEL PARTNERS AS RAW SOURCE

本目录存放 AI-Courses 的核心研发母版与可形成渠道壁垒的内部资产。

## 原则

代理商/授课教师可以获得：

- 当期授权课程；
- 对应教师操作材料；
- 学生任务卡；
- 当前课需要使用的模板/入口；
- 必要的故障恢复路径；
- 培训和认证材料。

但不默认获得：

- 完整母版库；
- 全学期所有核心 Prompt 源文件；
- 未发布版本；
- 失败案例库；
- Prompt/模板 A/B 测试记录；
- 下一版本路线；
- 所有课程可复用底层机制的完整映射。

目标不是人为制造使用困难，而是：

> **让代理教师可以高质量交付当前授权课程，但复制一套完整、可持续更新的课程研发体系仍需要重新投入大量研发。**
