# AI-Courses 教师课前 10 分钟检查表 V0.1

更新时间：2026-09-25  
状态：INTERNAL DELIVERY / TEACHER-FACING SOURCE

用途：

> 教师正式上课前，用 10 分钟确认“今天这节课能正常开”。

本页最终由 Teacher Portal 在当前授权课中显示，不作为完整文件包交给代理商。

---

# 一、今天上哪一课

确认：

- [ ] 学校和班级正确
- [ ] 当前课次正确
- [ ] 当前教师账号可以打开本节教学页
- [ ] 本节示例作品可以打开
- [ ] 本节学生任务二维码 / 入口可生成

如果课次不对，不自己切换未授权课程，联系课程方确认。

---

# 二、教师设备

- [ ] 教师电脑能正常上网
- [ ] 浏览器能正常打开课程平台
- [ ] 微信小程序教育平台可正常登录
- [ ] 投屏正常
- [ ] 声音正常（本课需要声音时）
- [ ] 鼠标 / 键盘 / 触控正常

---

# 三、学生环境

按学校实际方式抽查 1–2 台学生设备：

- [ ] 能打开学生任务页
- [ ] 能进入微信小程序教育平台
- [ ] 能正常输入文字
- [ ] 能预览作品
- [ ] 网络速度可接受

不需要课前逐台检查全班电脑。

如果抽查已经失败，先解决共性问题，不等学生全部进教室后再发现。

---

# 四、本节老师只需要准备的东西

Teacher Portal 当前课页面会列出本节专用项。

老师确认：

- [ ] 演示作品
- [ ] 需要投屏的示例
- [ ] 本节特殊材料
- [ ] 本节统一学生起点
- [ ] 本节关键时间点
- [ ] 本节“学生卡住时怎么办”
- [ ] 做得快学生的下一步

老师不需要另外打开研发文档准备。

---

# 五、二维码 / 发布相关课

如果本节会扫码、发布或展示：

- [ ] 教师示例二维码可打开
- [ ] 手机扫码网络正常
- [ ] 学生体验链接与后台编辑链接区分清楚

L15 / L16 等发布课再确认：

- [ ] 作品卡模板可用
- [ ] 作品墙位置 / 投屏方式准备好
- [ ] 最佳截图规则已知

---

# 六、开课前最后判断

如果下面四项都通过，就可以正常开课：

- [ ] 教师能看本节教学页
- [ ] 学生能进入创作平台
- [ ] 演示作品能打开
- [ ] 投屏能用

其他小问题不要无限拖延开课。

---

# 七、如果平台异常

正常情况下教师不能自行下载完整教案作为备用。

如果课程平台出现故障并影响上课：

1. 立即通过指定支持渠道联系课程方；
2. 提供：学校、班级、教师、当前课次、故障现象；
3. 等课程方确认处理方式；
4. 如需离线应急，由课程方人工授权当前课材料，或直接发送带身份水印的本课应急内容；
5. 不自行索取、保存或转发后续课 / 整学期资料。

详细 SOP：

`PLATFORM_INCIDENT_EMERGENCY_SOP_V0.1.md`

---

# 八、老师不需要做什么

- 不需要课前读完整学期教师手册；
- 不需要检查代码；
- 不需要自己制作本节 Prompt；
- 不需要临时搜索教学素材；
- 不需要自己设计快学生任务；
- 不需要准备整学期离线资料。

一句话：

> **上课前确认“人能进、课能看、作品能开、屏能投”，然后按当前课页面执行。**
