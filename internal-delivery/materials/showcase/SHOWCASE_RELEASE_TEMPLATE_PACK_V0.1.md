# AI-Courses 展示与发布通用模板包 V0.1

更新时间：2026-09-25  
状态：INTERNAL TEACHING MATERIAL / SHARED  
适用：小学 L15/L16、初中 L15/L16、Demo Day、作品墙、学校成果展示

目标：

> 不让老师临场设计“怎么展示作品”。所有班级采用统一、低负担、可拍照、可传播的成果格式。

---

# 一、作品卡模板

每个学生/小组只需要一张卡。

## 小学版

- 作品名：
- 作者：
- 我做的是什么：
- 我自己改的一条规则 / 功能：
- 我最满意的地方：
- 二维码：

一句话模板：

> “我做的是【作品】，它可以【核心功能】，我自己把【一处设计】改成了【结果】。”

## 初中版

- 产品名：
- 作者 / 小组：
- 主要用户：
- 解决的问题：
- 3个以内核心功能：
- 我做的一个关键取舍：
- 二维码：

一句话模板：

> “我们为【用户】做了【产品】，最重要的是帮助他们【核心任务】。V1之后我们把【原设计】改成【新设计】，因为【理由】。”

---

# 二、二维码作品墙模板

每个作品格只保留：

1. 作品名；
2. 作者；
3. 一张最佳截图；
4. 一句话介绍；
5. 二维码。

不要放：

- 大段教案；
- Prompt；
- 代码；
- 调试过程；
- 技术栈说明。

推荐布局：

> 一张 A3 / 大屏页面放 6–9 个作品。

每个作品格保证：

- 标题能看清；
- 二维码足够大；
- 最佳截图不是后台编辑界面；
- 一句话不超过两行。

---

# 三、最佳截图规范

学生最终至少保存一张：

> **别人第一眼最容易看懂这个作品价值的画面。**

优先：

- 游戏：正在玩 / 通关 / 规则触发；
- 学习产品：学习页 / 闯关 / 反馈；
- 工具：仪表盘 / 状态 / 完成结果；
- 故事：关键分支 / 结局；
- 博物馆：展区 / 收藏 / 挑战；
- 认知课：修改前后对比。

不要优先截：

- 平台后台；
- AI聊天界面；
- 代码；
- 空白首页；
- 加载中页面。

---

# 四、Before / After 模板

适用于：

- 用户测试；
- AI评审；
- 事实核查；
- AI反方；
- UX改进；
- Final V1 → V2。

统一四格：

| 修改前 | 我发现的问题 | 我做的决定 | 修改后 |
|---|---|---|---|
| 截图/一句话 | 用户/AI/来源指出什么 | 我采纳/拒绝/修改什么 | 截图/一句话 |

学生介绍模板：

> “原来是【A】。后来我发现【问题】。我决定【处理方式】。现在变成【B】。”

价值：

> 让学校和家长直接看到“学生不是一键生成，而是在判断和迭代”。

---

# 五、30秒作品介绍模板

适合小学 / 快速作品墙。

结构：

### 0–5秒
> “我的作品叫【名字】。”

### 5–12秒
> “它可以【核心功能】。”

### 12–20秒
> “我自己设计 / 修改了【一件事】。”

### 20–27秒
> “我后来发现【问题】，所以改了【结果】。”

### 27–30秒
> “你可以扫这个二维码试试。”

不要背长稿。

---

# 六、60秒产品发布模板

适合初中 Demo Day。

### 0–10秒｜用户和问题
> “我们想帮助【用户】解决【问题】。”

### 10–25秒｜产品
> “我们的产品可以【核心任务】，主要有【1–3个功能】。”

### 25–40秒｜迭代
> “第一版有【问题】。我们通过【用户测试 / AI评审 / 事实核查】发现以后，把它改成了【新版本】。”

### 40–50秒｜一个关键决定
> “我们没有做【功能/建议】，因为【理由】。”

### 50–60秒｜邀请体验
> “这是二维码，你可以实际试一下。”

---

# 七、教师收集作品的最小字段

每节展示课不让老师整理复杂表格。

只收：

- 班级；
- 学生编号 / 姓名（按学校规则）；
- 作品名；
- 作品类型；
- 作品二维码 / 链接；
- 最佳截图；
- 一句话介绍；
- 是否同意用于校内成果展示（按学校流程）；
- 教师标记：普通 / 推荐展示 / 需要修复。

不要要求长篇学生反思。

# 八、Demo Day 摊位卡

每个作品桌面 / 屏幕前：

## 产品名

【产品名】

## 给谁用

【用户】

## 它能做什么

【核心任务】

## 我们改过什么

【最重要的一次迭代】

## 扫码体验

【二维码】

初中可以再加：

> “我们拒绝 / 删除的一项设计：【内容】”

# 九、课堂发布检查

发布前最后检查：

- [ ] 作品能打开
- [ ] 核心流程能走完
- [ ] 二维码可用
- [ ] 最佳截图已保存
- [ ] 作品名清楚
- [ ] 一句话介绍完成
- [ ] 没有明显个人敏感信息
- [ ] 没有把后台编辑链接当体验链接

---

# 十、学校成果页推荐结构

一页学校成果只需要：

## 1. 一句话课程价值

> 从“问AI”到“用AI创造”。

## 2. 本学期作品类型

用6–8张代表图展示：

- 游戏；
- 学习App；
- 互动世界；
- 博物馆；
- 工具；
- Final产品。

## 3. 学生能力变化

只写可见动作：

- 会把想法说清楚；
- 会实际测试；
- 会判断AI建议；
- 会核查关键事实；
- 会根据用户反馈修改；
- 会发布并介绍自己的产品。

## 4. 精选作品

每个作品：

截图 + 一句话 + 二维码。

不要把成果页写成课程理论白皮书。

---

# 十一、隐私与对外展示提醒

正式对外展示前，课程方 / 学校应按学校要求确认：

- 学生姓名使用方式；
- 学生照片 / 视频授权；
- 作品中是否含真实电话、地址、账号等信息；
- 二维码是否指向公开允许体验的版本；
- 是否需要使用名字缩写或编号。

本模板只定义课程展示结构，不替代学校自己的未成年人信息与影像授权流程。

---

# 十二、Teacher Portal 中的使用方式

完整模板包保留在课程方内部。

授课教师在对应课次只看到本课需要的模板，例如：

- L15：发布检查 + 最佳截图 + 一句话介绍；
- L16：作品卡 + 二维码作品墙 + 30秒 / 60秒介绍；
- L9/L10/L11/L12：Before / After；
- Demo Day：摊位卡 + 60秒发布。

代理商不需要获得完整模板源库。
