# Internal Delivery Source

更新时间：2026-09-25  
状态：INTERNAL ONLY / NOT FOR AGENT DISTRIBUTION

这里存放的是课程方内部的“教师最终页面源稿”。

用途：

- 作为完整教师手册的内部源内容；
- 作为 Teacher Portal 单课页面的内容来源；
- 作为课堂投屏和学生任务页的编译来源；
- 用于内部走课和版本审核。

不得把本目录完整交给代理商。

正式授课时，认证教师只通过 Teacher Portal 查看当前被授权课次的整合页面。正常情况下不提供下载、导出或整学期离线包。

## 单课统一结构

每一课尽量只用一个源文件表达教师真正需要的全部信息：

1. 老师一分钟先看；
2. 课前准备；
3. 逐分钟怎么带；
4. 老师关键话术；
5. 到什么时间全班应该做到哪里；
6. 学生卡住时怎么处理；
7. 多人同时卡住怎么处理；
8. 做得快的学生接下来做什么；
9. 下课如何收口；
10. 课堂投屏内容源；
11. 学生任务页内容源；
12. 课后一分钟记录。

内部研发术语可以留在原始课程文件中，这里的教师页面只使用普通教师容易理解的语言。

## 当前四节样板

第一轮覆盖四种典型课型：

- 小学 L1：第一次创作课；
- 小学 L15：测试与发布课；
- 初中 L3：规则逻辑课；
- 初中 L9：AI判断 / 认知课。

四节内部走课通过后，再固定格式并批量铺其余课程。
